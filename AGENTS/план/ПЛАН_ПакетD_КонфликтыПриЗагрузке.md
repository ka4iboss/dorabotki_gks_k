# ПЛАН: Пакет D — конфликты при загрузке (версия 1.7)

**Версия расширения:** 1.7.
**Родительский план:** `AGENTS/план/ПЛАН_РазвитиеПодсистемВерсия17.md` §6.
**Статус:** ✅ сделано пользователем.

## 1. Цель

Сделать поток «выбрал файл → нажал Загрузить → система сама спросила, что делать с конфликтами» прозрачным: убрать отдельную кнопку «Проверить конфликты» из UI, вынести проверку внутрь потока «Загрузить», показать диалог с вариантами «Разрешить / Обновить все / Пропустить все», при выборе «Разрешить» открывать форму разрешения конфликтов.

## 2. Состав пакета

| Подпакет | Содержимое | Статус |
|----------|------------|--------|
| D1. Скрыть отдельную кнопку «Проверить конфликты» | В `Form.form` установить `Видимость = Ложь` для кнопки `ПроверитьКонфликтыКнопка`; обработчик оставить как сервисный (для обратной совместимости и тестов) | ✅ сделано |
| D2. Автоматический вызов проверки при «Загрузить» | В `ВыполнитьЗагрузку` после успешного парсинга — вызвать `ПодготовитьДанныеДляФормыКонфликтов`, если конфликтов нет — сразу запустить фоновую запись, иначе показать меню из 3 пунктов | ✅ сделано |
| D3. Форма разрешения принимает массив | В `ПриСозданииНаСервере` `ФормаРазрешенияКонфликтов` читать `Параметры.МассивКонфликтов` (прямая передача) с фолбэком на ВХ; `ЗаполнитьТаблицуКонфликтов` — `ЗаполнитьЗначенияСвойств` + `Решение = "Пропустить"` | ✅ сделано |

## 3. Что было реализовано

### 3.1. D1 — скрытие кнопки

В `Form.form` обработки `ГКСИ_ЗагрузкаСценариевИзMarkdown` кнопке `ПроверитьКонфликтыКнопка` через `1C_EditMetadata` установлен `visible=false`. Команда и обработчик `ПроверитьКонфликты` сохранены как сервисные для обратной совместимости.

### 3.2. D2 — автовызов при «Загрузить»

1. `ВыполнитьЗагрузку` сначала вызывает серверную функцию `ПодготовитьДанныеДляФормыКонфликтов()`, которая возвращает `Структура{МассивКонфликтов, КоличествоКонфликтов}`.
2. Если конфликтов нет — сразу запускается фоновая запись через `ЗапуститьЗагрузкуСейчас()`.
3. Если конфликты есть — формируется `СписокЗначений` из 3 пунктов («Разрешить конфликты…», «Обновить все существующие», «Пропустить все существующие») и показывается через `ПоказатьВыборЭлемента`.
4. Массив конфликтов передаётся в `ОписаниеОповещения` через `ДопПараметры`, чтобы обработчик `ПослеВыбораДействияПоКонфликтам` имел его на клиенте.
5. Для «Разрешить» — массив передаётся в форму разрешения через `ПараметрыФормы` напрямую.
6. Для «Обновить все» / «Пропустить все» — серверная функция `СформироватьРешенияПоВсемКонфликтам(МассивКонфликтов, Действие)` строит соответствие `{ИмяИзФайла -> {Действие, Ссылка}}` без обращения к ВХ; потом сразу `ЗапуститьЗагрузкуСейчас()`.

### 3.3. D3 — форма разрешения

`ПриСозданииНаСервере` в `ФормаРазрешенияКонфликтов/Module.bsl`:
- читает `Параметры.МассивКонфликтов` через `Параметры.Свойство(...)`;
- пишет в ЖР по событию `ГКСИ.ЗагрузкаСценариевИзMarkdown.ПроверкаКонфликтов` тип и количество;
- вызывает `ЗаполнитьТаблицуКонфликтов(МассивКонфликтов)` — копирует поля структур (`ИмяИзФайла`, `СуществующаяСсылка`, `СуществующееЭтоГруппа`) через `ЗаполнитьЗначенияСвойств`, для колонки `Решение` ставит значение по умолчанию `"Пропустить"`.
- `НастроитьКолонкуРешения` настраивает список выбора «Пропустить / Обновить / Дублировать».
- форма не делает собственных запросов к БД.

## 4. Архитектурное решение: почему не ВХ

Первая попытка с привязкой адреса ВХ к `УникальныйИдентификатор` основной формы не сработала: у формы разрешения другой УИД, чтение по нему возвращало `Неопределено`, таблица оставалась пустой. Прямая передача массива структур через `ПараметрыФормы` снимает эту проблему и убирает ошибку компиляции на двухпараметровом `ПолучитьИзВременногоХранилища(Адрес, УИД)` — документация платформы подтверждает, что метод имеет ровно один обязательный параметр.

## 5. Открытая проблема

Если у пользователя форма разрешения всё ещё открывается пустой — возможно, требуется проверить обновление конфигурации БД (F7 в EDT) и перезапустить сеанс 1С:Предприятия. Подробности — в `AGENTS/отчёт/ОТЧЁТ_БагПустаяФормаРазрешенияКонфликтов_ГКСИ_ЗагрузкаСценариевИзMarkdown.md.bak`.
