# ПЛАН: Пакет A — расширение загрузки сценариев из Markdown (версия 1.7)

**Версия расширения:** 1.7.
**Родительский план:** `AGENTS/план/ПЛАН_РазвитиеПодсистемВерсия17.md` §3.
**Статус:** A1 — сделано (пользователь, без расширения); A2, A3, A4 — к реализации.

## 1. Цель

Расширить обработку `ГКСИ_ЗагрузкаСценариевИзMarkdown` так, чтобы она корректно обрабатывала существующие сценарии при повторной загрузке, валидировала входящие файлы картинок, понимала абсолютные пути и http(s)-URL, и давала пользователю фильтровать загружаемое по разделам файла.

## 3. A2. Валидация MIME при импорте картинок

### 3.1. Проблема

Картинки из Obsidian `![[path]]` сейчас записываются в `ГКСИ_ФайлыИнструкций` по расширению файла. Если по факту в файле `evil.exe`, переименованный в `evil.png`, расширение скажет «PNG», а MIME — `application/x-msdownload`. Сейчас проверки нет.

### 3.2. Что сделать

1. В `ГКСИ_ЗагрузкаСценариевИзMarkdown.ЗагрузитьФайлыКартинок` (или эквивалентный метод) перед записью прочитать первые 8 байт файла и определить MIME сигнатурно:
   - `89 50 4E 47` → `image/png`;
   - `FF D8 FF` → `image/jpeg`;
   - `47 49 46 38` → `image/gif`;
   - `42 4D` → `image/bmp`;
   - `3C 3F 78 6D 6C` или `3C 73 76 67` → `image/svg+xml`;
   - иное → отказ.
2. При несоответствии расширения и MIME — регистрировать как конфликт «Файл отклонён (MIME/расширение)» с тремя вариантами действий:
   - «Принять как есть (с приведением расширения)»;
   - «Отклонить»;
   - «Открыть для просмотра».
3. Если ни один конфликт не выбран — файл пропускается.
4. Логика валидации — отдельная экспортная функция `ГКСИ_ЗагрузкаСценариевИзMarkdown.MIMEПоСигнатуре(ДвоичныеДанные)`, чтобы переиспользовать в других местах.

### 3.3. Файлы

- `src/CommonModules/ГКСИ_ЗагрузкаСценариевИзMarkdown/Module.bsl` — `MIMEПоСигнатуре`, обновить `ЗагрузитьФайлыКартинок`.

## 4. A3. Абсолютные пути и URL для картинок

### 4.1. Проблема

В `ПодменитьСсылкиНаКартинкиВТексте` обрабатываются только относительные пути. Абсолютные пути (`C:\…`, `\\server\share\…`) и URL (`https://…`) обработка не подхватывает.

### 4.2. Что сделать

1. Расширить парсер ссылок в `ПодменитьСсылкиНаКартинкиВТексте` тремя дополнительными типами:
   - абсолютный путь Windows (`^[A-Za-z]:\\` или `^\\\\` для UNC);
   - URL (`^https?://`);
   - `file://` — по тому же алгоритму, что и абсолютный путь, без префикса `file:///`.
2. Для абсолютных путей — копировать файл через `ПолучитьДвоичныеДанныеИзФайла`, помещать во временное хранилище.
3. Для URL — `HTTPСоединение.Получить(...)` с таймаутом 30 секунд, размер не более 5 МБ (константа `ГКСИ_ЗагрузкаСценариевИзMarkdown.МАКС_РАЗМЕР_ФАЙЛА_URL = 5 * 1024 * 1024`).
4. При ошибке загрузки URL — конфликт «Не удалось загрузить URL», варианты: «Пропустить», «Открыть в браузере».

### 4.3. Файлы

- `src/CommonModules/ГКСИ_ЗагрузкаСценариевИзMarkdown/Module.bsl` — расширение `ПодменитьСсылкиНаКартинкиВТексте`, новые экспортные `СкачатьПоURL`, `ПолучитьДвоичныеДанныеИзАбсолютногоПути`.
- опционально: общий модуль `ГКСИ_HTTPКлиент` с настройками таймаута и лимита размера.

## 5. A4. Фильтрация по разделам при повторной загрузке

### 5.1. Проблема

Сейчас при загрузке берётся весь файл целиком; если нужно обновить только один раздел, приходится редактировать `.md`-файл руками.

### 5.2. Что сделать

1. В форме `Форма` обработки добавить таблицу `ВыбранныеРазделы` (`Заголовок`, флажок `Включать`). Изначально заполняется при парсинге всеми заголовками H1/H2; по умолчанию все флажки включены.
2. Перед записью в `ЗаписатьДеревоВСправочник` отфильтровать узлы по флажкам: если в `ДеревоУзлов` у узла ни один предок не отмечен — узел не пишется.
3. Передача в фон (`ДлительныеОперации.ВыполнитьВФоне`) — сериализованный массив `ЗаголовокВключать`.

### 5.3. Файлы

- `src/DataProcessors/ГКСИ_ЗагрузкаСценариевИзMarkdown/Forms/Форма/Form.form` — таблица `ВыбранныеРазделы`.
- `src/DataProcessors/ГКСИ_ЗагрузкаСценариевИзMarkdown/Forms/Форма/Module.bsl` — заполнение таблицы при парсинге, передача в фон.
- `src/CommonModules/ГКСИ_ЗагрузкаСценариевИзMarkdown/Module.bsl` — фильтрация узлов.
- `src/CommonModules/ГКСИ_ЗагрузкаСценариевИзMarkdownДлительныеОперации/Module.bsl` — приём массива разделов.
