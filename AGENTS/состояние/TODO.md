### Архитектурные решения (не забыть)

1. **Иерархия групп строится через РС `ГКСИ_ГруппыСценариев`** — стандартное
   поле `Родитель` обнуляется в `ObjectModule.ГКСИ_ПередЗаписью`.
2. **Имя файла описания**: `<GUID_сценария>_<КодЯзыка>` — без префикса
   "ОписаниеСценария_". За формирование отвечает
   `ГКСИ_ГруппыСценариевСервер.ИмяФайлаОписанияСценария()`.
3. **Полный код контекстный** хранится в ресурсе `ПолныйКодКонтекстный` РС,
   пересчитывается в `ObjectModule.ГКСИ_ПриЗаписи` для всей подветки группы.
4. **Форма списка по умолчанию** — `ФормаСпискаДеревоГрупп`
   (одна строка на каждую пару «сценарий ↔ группа»).
5. **Кеш изображений Markdown** — `ГКСИ_ДанныеИзображенийMarkdownПовтИсп`
   с `ReturnValuesReuse = DuringSession`. Экспортная функция
   `СоответствиеКодДанные` принимает **строку-ключ**
   `"<Код1>|<Код2>|...#<Ширина>"`, потому что платформа режет типы
   параметров кешируемой экспортной функции (Массив нельзя, Строка можно).
   Обёртка `ГКСИ_MarkdownПереопределяемый.СоответствиеКодДанныеИзображений`
   формирует ключ из массива кодов и ширины. Подробности — в
   `AGENTS/отчёт/ОТЧЁТ_ОбходКешаИзображенийИзФоновогоЗадания.md`.
6. **Подмена ссылок на картинки в Markdown** — в
   `ГКСИ_ЗагрузкаСценариевИзMarkdown.ПодменитьСсылкиНаКартинкиВТексте`
   реализована через единый проход двумя regex (Obsidian + стандартный
   markdown) с накоплением массива замен `{Позиция, Длина, Текст}` и
   применением с конца строки. Это нужно, чтобы замена одного совпадения

   `❌ <путь>`. Поддерживаются `![[path]]`, `![[path|extra]]`, `![alt](path)`.
   Подробности — в `AGENTS/отчёт/ОТЧЁТ_ПоддержкаВариантовКартинокВMarkdown.md`.
