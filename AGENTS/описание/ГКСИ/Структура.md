# Структура подсистемы ГКСИ расширения «Доработки_ГКС_К»

> **Документ перенесён** из расширения `пустая_для_гкс.ГКС_Инструкции` в объединённое
> расширение `Доработки_ГКС_К`; имена объектов приведены к фактическим (`РМ_` → `ГКСИ_`).
> Карта переименований — `описание/Описание.md` §5.

Документ содержит состав объектов подсистемы ГКСИ и их расположение в файловой структуре
проекта `R:\EDTProjects\GGKKSS\Доработки_ГКС_К`. Описывает две подсистемы:
**«Инструкции и описания демонстраций»** (`ГКСИ_ИнструкцииОписанияДемонстраций`) и
**«Редактор Markdown»** (`ГКСИ_РМ_РедакторMarkdown`).

Логика работы объектов — в `описание/ГКСИ/Описание.md`. Общая карта расширения и
переименования при объединении — в корневых `описание/Описание.md` и `описание/Структура.md`
(здесь не дублируются).

## 1. Параметры конфигурации расширения

- **Имя конфигурации:** `Доработки_ГКС_К`
- **Синоним:** Доработки ГКС К
- **Префикс имён (`namePrefix`):** `ГКСК`
- **Назначение (purpose):** `Customization`
- **Принадлежность:** `Adopted` (расширение конфигурации)
- **Режим совместимости расширения:** `8.3.27`
- **Версия платформы:** `8.3.27`
- **Вариант встроенного языка:** Русский
- **Основной режим запуска:** `ManagedApplication`
- **Назначения использования:** `PersonalComputer`
- **Интерфейс совместимости:** `TaxiEnableVersion8_2`
- **Версия расширения:** `2.35.1`
- **Родительская конфигурация:** `пустая_для_гкс` (1С:ERP УП 2, 2.5.26.118)
- **Файл описания:** `src/Configuration/Configuration.mdo`

Подключаемые модули расширения (`ManagedApplicationModule`, `SessionModule`,
`ExternalConnectionModule`) — пустые; интерфейсы команд — `CommandInterface.cmi`,
`MainSectionCommandInterface.cmi`.

## 6. Справочники (`Catalogs`)

### 6.1 Собственные справочники

#### `ГКСИ_ФайлыИнструкций`

- **Файл `.mdo`:** `src/Catalogs/ГКСИ_ФайлыИнструкций/ГКСИ_ФайлыИнструкций.mdo`
- **Синоним:** ГКСИ файлы инструкций
- **Комментарий:** Хранилище изображений и файлов для инструкций
- **Иерархия:** 2 уровня, папки сверху
- **Длина кода:** 36 (строка, переменная); **длина наименования:** 150; **контроль уникальности:** Да
- **Представление:** КакНаименование
- **Формы:** отсутствуют (работа только программная)

| Реквизит | Тип | Длина | Индекс | Комментарий |
|----------|-----|-------|--------|-------------|
| `Файл` | `ValueStorage` | — | | Двоичные данные файла |
| `Расширение` | `String` | 10 | | Расширение файла без точки (png, jpg, gif и т.д.) |
| `Описание` | `String` | 100 | | Краткое описание файла |
| `ХешSHA256` | `String` | 64 | Да | SHA-256 от двоичных данных `Файл`. Используется для дедупликации при импорте картинок из Markdown |

> Элементы создаются в `ГКСИ_MarkdownПереопределяемый.ЗаписатьПрисоединенныйФайлВБазу`
> (код = GUID-строка, расширение и двоичные данные сохраняются в реквизит `Файл` через
> `Новый ХранилищеЗначение(...)`).

## 9. Обработки (`DataProcessors`)

### 9.1 `ГКСИ_РедакторMarkdownПример`

- **Файл `.mdo`:** `src/DataProcessors/ГКСИ_РедакторMarkdownПример/`
- **Синоним:** Редактор markdown пример; **DefaultForm:** `...Form.Форма`
- **Реквизит объекта:** `ТекстМД` (String, неограниченная)
- **Форма:** `Forms/Форма/` (`Form.form`, `Module.bsl`) — реквизиты `Объект`,
  `ТекстРедактирования`, `ВариантПодсветкиСинтаксиса`, `ТекстТолькоПросмотр`; элементы
  `ВариантПодсветки`, `ГруппаСтраницыРедакторов` (Pages). Служит заготовкой для интеграции
  подсистемы Markdown в произвольную форму.

### 9.2 `ГКСИ_ЗагрузкаСценариевИзMarkdown`

- **Файл `.mdo`:** `src/DataProcessors/ГКСИ_ЗагрузкаСценариевИзMarkdown/`
- **Синоним:** Загрузка сценариев из Markdown; **DefaultForm:** `...Form.Форма`;
  **useStandardCommands:** `true`
- **Назначение:** импорт иерархии групп и элементов справочника `ДемонстрационныеСценарии`
  из Markdown-файла.
- **Формы:**
  - `Форма` — `Forms/Форма/` (`Form.form` + `Module.bsl`): 4 шага — выбрать каталог, загрузить,
    проверить конфликты, выполнить загрузку; загрузка в фоновом задании.
  - `ФормаРазрешенияКонфликтов` — `Forms/ФормаРазрешенияКонфликтов/` (`Form.form` + `Module.bsl`):
    таблица конфликтов с вариантами `Пропустить` / `Обновить` / `Дублировать` /
    `Прикрепить к нашей группе`.
- **Серверная логика:** `CommonModule.ГКСИ_ЗагрузкаСценариевИзMarkdown`,
  `CommonModule.ГКСИ_ЗагрузкаСценариевИзMarkdownДлительныеОперации` (см. `описание/ГКСИ/Описание.md` §11).

### 9.3 `ГКСИ_ВыгрузкаСценариевВMarkdown`

- **Файл `.mdo`:** `src/DataProcessors/ГКСИ_ВыгрузкаСценариевВMarkdown/`
- **Синоним:** Выгрузка сценариев в Markdown; **DefaultForm:** `...Form.Форма`;
  **useStandardCommands:** `true`
- **Назначение:** обратная операция к загрузке — выгрузка инструкций (корневых обёрток) в
  `.md`-файлы. Источник текста — `ДемонстрационныеСценарии.ГКСИ_ТекстMarkdown`.
- **Форма:** `Forms/Форма/` (`Form.form` + `Module.bsl`): команды `Выгрузить`, `ВыгрузитьВсе`,
  `ВыбратьКаталог`; фоновое задание с прогрессом; сохранение файлов на диск клиента.
- **Серверная логика:** `CommonModule.ГКСИ_ВыгрузкаСценариевВMarkdown`,
  `CommonModule.ГКСИ_ВыгрузкаСценариевВMarkdownДлительныеОперации` (см. `описание/ГКСИ/Описание.md` §12).
