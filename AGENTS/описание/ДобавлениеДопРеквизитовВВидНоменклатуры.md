# Подбор дополнительных реквизитов в виде номенклатуры

## Назначение

В форме элемента справочника **`Справочник.ВидыНоменклатуры`** (`Форма.ФормаЭлемента`,
страница «Дополнительные реквизиты») в меню **«Добавить»** таблицы «Реквизиты номенклатуры»
появился пункт **«Добавить доп реквизит»**.

Команда открывает `ПланВидовХарактеристик.ДополнительныеРеквизитыИСведения.Форма.ФормаСписка`
в режиме **выбора** и **только с дополнительными реквизитами** (дополнительные сведения
в списке не показываются). Выбранный реквизит добавляется в основной набор вида номенклатуры
(`Справочник.НаборыДополнительныхРеквизитовИСведений`, набор `Объект.НаборСвойств`).
Чтобы добавить несколько реквизитов, команду вызывают несколько раз.

Штатные пункты меню («Новый для вида», «Из другого набора...», «Общий для всей номенклатуры»)
сохранены без изменений.

## Состав изменений (расширение `Доработки_ГКС_К`)

Форма `Справочник.ВидыНоменклатуры.Форма.ФормаЭлемента` **заимствована** в расширение
(файлы `Form.form`, `Module.bsl`, `BaseForm/Form.form`).

Также **заимствована** форма `ПланВидовХарактеристик.ДополнительныеРеквизитыИСведения.Форма.ФормаСписка`
(`Form.form`, `BaseForm/Form.form`, `Module.bsl`): в её модуле расширения по собственному
параметру `ГКСК_ВыборДопРеквизита` включается режим выбора таблицы (см. «Логика работы»).

| Объект формы | Назначение |
|---|---|
| Команда `ГКСК_ДобавитьДопРеквизитИзСписка` | Открытие списка дополнительных реквизитов и добавление выбранного |
| Кнопка `НоменклатураДобавитьДопРеквизитИзСписка` | Пункт в popup-группе `НоменклатураГруппаСоздатьРеквизиты` (меню «Добавить» у таблицы «Реквизиты номенклатуры») |
| Обработчик `ГКСК_ОбработкаВыбора(ВыбранноеЗначение, ИсточникВыбора)` | Приём результата выбора событием формы |
| Обработчик `ГКСК_ДобавитьДопРеквизитИзСпискаЗавершение(ВыбранноеЗначение, ДополнительныеПараметры)` (`Экспорт`) | Приём результата через `ОписаниеОповещения` (резервный путь) |
| Реквизит формы `ГКСК_ВыборДопРеквизитаОбработан` (`Булево`) | Защита от двойной обработки одного и того же выбора |

## Логика работы

1. `ГКСК_ДобавитьДопРеквизитИзСписка` (клиент) проверяет, что вид номенклатуры записан
   и что заполнен `Объект.НаборСвойств`; иначе выводит предупреждение.
2. Открывается `ПланВидовХарактеристик.ДополнительныеРеквизитыИСведения.Форма.ФормаСписка`
   с параметрами:
   - `ГКСК_ВыборДопРеквизита = Истина` - собственный параметр: по нему заимствованная
     форма списка включает режим выбора таблицы (двойной клик по строке выбирает и закрывает форму);
   - `ВыборГруппИЭлементов = ИспользованиеГруппИЭлементов.Элементы`;
   - `Отбор = Новый Структура("ЭтоДополнительноеСведение", Ложь)` - доп. сведения отсекаются.
   Владелец - `ЭтотОбъект`; режим открытия окна - `РежимОткрытияОкнаФормы.БлокироватьОкноВладельца`
   (форма открывается поверх текущего окна, а не отдельной вкладкой).
   В заимствованной форме списка (`ChartsOfCharacteristicTypes/ДополнительныеРеквизитыИСведения/Forms/ФормаСписка/Module.bsl`)
   процедура `&НаСервере &После("ПриСозданииНаСервере") ГКСК_ПриСозданииНаСервере` при наличии
   параметра `ГКСК_ВыборДопРеквизита` выполняет `Элементы.Список.РежимВыбора = Истина`.
   Без параметра форма работает как обычно.
3. `ГКСК_ДобавитьДопРеквизитИзСпискаЗавершение` (клиент, `Экспорт`) при `Неопределено`
   (отказ от выбора) выходит; иначе приводит результат к массиву ссылок
   (`ГКСК_МассивСвойствИзВыбора`: значение, массив или строка динамического списка -
   нормализуется через `Свойство("Ссылка", ...)`) и вызывает серверную
   `ГКСК_ДобавитьСвойстваВНабор`.
4. `ГКСК_ДобавитьСвойстваВНабор` (сервер):
   - одним запросом читает `Заголовок`, `ПометкаУдаления`, `ЭтоДополнительноеСведение`
     по массиву выбранных ссылок (обращений к БД в цикле нет);
   - пропускает уже присутствующий в таблице реквизит, отсутствующий в базе и доп. сведения;
   - добавляет строку в **таблицу формы** `ТаблицаДопРеквизитовНоменклатуры`:
     `Свойство`, `ОбщееСвойство = Ложь`, `ПредставлениеРеквизита = Заголовок`,
     `ИндексКартинки = 4` для помеченного на удаление, иначе `1`.
5. В табличное поле «Реквизиты номенклатуры» строка попадает сразу; в ТЧ набора
   (`ДополнительныеРеквизиты`) она переносится **штатным** `ПриЗаписиНаСервере` →
   `ЗаписатьДопРеквизитыСведенияНабора` при записи вида номенклатуры.
6. Если реквизит уже есть в наборе, выводится предупреждение.

## Принятые решения и ограничения

- Выбор **одиночный**: двойной клик по строке выбирает и закрывает форму. Множественный выбор
  отклонён: в списках с множественным выбором двойной клик открывает элемент, а выбор требует
  кнопки «Выбрать».
- **Почему режим выбора включается изнутри формы.** У плана видов характеристик
  `ДополнительныеРеквизитыИСведения` не задана форма выбора (`defaultChoiceForm` в `.mdo`
  отсутствует), поэтому `ФормаСписка` для платформы - обычная форма списка, и параметры
  `РежимВыбора` / `ЗакрыватьПриВыборе`, переданные в `ПараметрыФормы`, молча игнорируются
  (работает только параметр `Отбор`). Поэтому форма списка заимствована в расширение, и режим
  выбора таблицы (`Элементы.Список.РежимВыбора = Истина`) включается в её `ПриСозданииНаСервере`
  только при наличии параметра `ГКСК_ВыборДопРеквизита` - остальные вызовы формы (из раздела
  «Дополнительные реквизиты и сведения») работают как раньше.
- В модуле формы списка метод-перехватчик назван с префиксом (`ГКСК_ПриСозданииНаСервере`,
  SU61), размещён в `СлужебныеПроцедурыИФункции` (SU93) и объявлен с явной директивой
  `&НаСервере` - без неё EDT выдаёт SU248 «отличается сигнатура метода расширения».
- Результат принимается **событием формы** `ОбработкаВыбора` (`ГКСК_ОбработкаВыбора`): при
  владельце-форме платформа передаёт выбор именно туда. Дополнительно оставлен приём через
  `ОписаниеОповещения` (`ГКСК_ДобавитьДопРеквизитИзСпискаЗавершение`, `Экспорт`); повторная
  обработка исключается реквизитом `ГКСК_ВыборДопРеквизитаОбработан`.
- Форма открывается **поверх текущего окна** (`РежимОткрытияОкна = РежимОткрытияОкнаФормы.БлокироватьОкноВладельца`),
  а не отдельной вкладкой.
- Строка добавляется в **таблицу формы**, а не в ТЧ набора напрямую: так не теряются
  несохранённые правки таблицы и работает штатный механизм записи набора.
- Реквизит, уже присутствующий в таблице (включая строки «общих» реквизитов), не дублируется.
- Помеченный на удаление реквизит добавляется с индексом картинки `4` - как в штатном
  заполнении таблицы.
- Состав «Реквизиты для контроля» не затрагивается: он актуализируется штатно при записи.
- Выбор доступен только для записанного вида номенклатуры: набор свойств создаётся при записи.

## Версия

- Подсистема **ШаблоныНаименований**: `1.0.0` → `1.1.0`.
- Расширение: `1.0.22.12` → `1.0.23.0`.
