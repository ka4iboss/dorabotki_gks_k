# Подбор дополнительных реквизитов в виде номенклатуры

## Назначение

В форме элемента справочника **`Справочник.ВидыНоменклатуры`** (`Форма.ФормаЭлемента`,
страница «Дополнительные реквизиты») в меню **«Добавить»** таблицы «Реквизиты номенклатуры»
появился пункт **«Добавить доп реквизит»**.

Команда открывает `ПланВидовХарактеристик.ДополнительныеРеквизитыИСведения.Форма.ФормаСписка`
в режиме **множественного выбора** и **только с дополнительными реквизитами**
(дополнительные сведения в списке не показываются). Выбранные реквизиты добавляются
в основной набор вида номенклатуры (`Справочник.НаборыДополнительныхРеквизитовИСведений`,
набор `Объект.НаборСвойств`).

Штатные пункты меню («Новый для вида», «Из другого набора...», «Общий для всей номенклатуры»)
сохранены без изменений.

## Состав изменений (расширение `Доработки_ГКС_К`)

Форма `Справочник.ВидыНоменклатуры.Форма.ФормаЭлемента` **заимствована** в расширение
(файлы `Form.form`, `Module.bsl`, `BaseForm/Form.form`).

| Объект формы | Назначение |
|---|---|
| Команда `ГКСК_ДобавитьДопРеквизитИзСписка` | Открытие списка дополнительных реквизитов и добавление выбранных |
| Кнопка `НоменклатураДобавитьДопРеквизитИзСписка` | Пункт в popup-группе `НоменклатураГруппаСоздатьРеквизиты` (меню «Добавить» у таблицы «Реквизиты номенклатуры») |
| Реквизит формы `ТаблицаПодбораДопРеквизитов` (`ТаблицаЗначений`) | Пустая таблица-«приёмник» результата выбора |
| Элемент `ТаблицаПодбораДопРеквизитов` (таблица, `visible = false`) | Владелец открываемой формы; на её событие `ОбработкаВыбора` приходит результат |
| Обработчик `ГКСК_ТаблицаПодбораДопРеквизитовОбработкаВыбора(Элемент, ВыбранноеЗначение, СтандартнаяОбработка)` | Приём выбранных значений |

## Логика работы

1. `ГКСК_ДобавитьДопРеквизитИзСписка` (клиент) проверяет, что вид номенклатуры записан
   и что заполнен `Объект.НаборСвойств`; иначе выводит предупреждение.
2. Открывается `ПланВидовХарактеристик.ДополнительныеРеквизитыИСведения.Форма.ФормаСписка`
   с параметрами:
   - `РежимВыбора = Истина`;
   - `МножественныйВыбор = Истина`;
   - `ЗакрыватьПриВыборе = Ложь` (выбор нескольких позиций);
   - `ВыборГруппИЭлементов = ИспользованиеГруппИЭлементов.Элементы`;
   - `Отбор = Новый Структура("ЭтоДополнительноеСведение", Ложь)` - доп. сведения отсекаются.
   Владелец формы - элемент `ТаблицаПодбораДопРеквизитов`.
3. `ГКСК_ТаблицаПодбораДопРеквизитовОбработкаВыбора` ставит `СтандартнаяОбработка = Ложь`,
   приводит результат к массиву ссылок (`ГКСК_МассивСвойствИзВыбора`: массив или одиночное
   значение, отбрасываются повторы) и вызывает серверную `ГКСК_ДобавитьСвойстваВНабор`.
4. `ГКСК_ДобавитьСвойстваВНабор` (сервер):
   - одним запросом читает `Заголовок`, `ПометкаУдаления`, `ЭтоДополнительноеСведение`
     по массиву выбранных ссылок (обращений к БД в цикле нет);
   - пропускает уже присутствующие в таблице реквизиты, отсутствующие в базе и доп. сведения;
   - добавляет строки в **таблицу формы** `ТаблицаДопРеквизитовНоменклатуры`:
     `Свойство`, `ОбщееСвойство = Ложь`, `ПредставлениеРеквизита = Заголовок`,
     `ИндексКартинки = 4` для помеченных на удаление, иначе `1`.
5. В табличное поле «Реквизиты номенклатуры» строки попадают сразу; в ТЧ набора
   (`ДополнительныеРеквизиты`) они переносятся **штатным** `ПриЗаписиНаСервере` →
   `ЗаписатьДопРеквизитыСведенияНабора` при записи вида номенклатуры.
6. По результату выводится предупреждение: «уже есть в наборе» либо
   «добавлено / пропущено».

## Принятые решения и ограничения

- Владельцем открываемой формы выбрана **отдельная скрытая таблица**, а не существующая
  `ТаблицаДопРеквизитовНоменклатуры`: её штатный обработчик `ОбработкаВыбора` ожидает
  `Структура`/значение со свойством `ОбщееСвойство`, а не массив ссылок.
- Результат приходит через событие элемента `ОбработкаВыбора` (сигнатура из трёх параметров),
  без асинхронных оповещений - в этой базе оповещения ненадёжны.
- Строки добавляются в **таблицу формы**, а не в ТЧ набора напрямую: так не теряются
  несохранённые правки таблицы и работает штатный механизм записи набора.
- Реквизиты, уже присутствующие в таблице (включая строки «общих» реквизитов), не дублируются.
- Помеченный на удаление реквизит добавляется с индексом картинки `4` - как в штатном
  заполнении таблицы.
- Состав «Реквизиты для контроля» не затрагивается: он актуализируется штатно при записи.
- Выбор доступен только для записанного вида номенклатуры: набор свойств создаётся при записи.
