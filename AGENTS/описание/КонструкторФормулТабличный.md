# Табличный конструктор формулы (`ОбщаяФорма.КонструкторФормул`)

Доработка заимствованной общей формы `КонструкторФормул` (расширение
`Доработки_ГКС_К`). Подсистема **ШаблоныНаименований**, версия `1.2.0`.

## Назначение

Типовой конструктор даёт одно большое поле «Формула», куда нужно вручную писать
выражение вида:

```
"Двутавр"
+?(ЗначениеЗаполнено([{ДР.НомерДвутавра}]), " " +[{ДР.НомерДвутавра}], "")
+?(ЗначениеЗаполнено([{ДР.Стандарт}]), " ГОСТ " +[{ДР.Стандарт}], "")
```

Для строковых формул (шаблоны наименований номенклатуры, характеристик, серий)
вместо этого поля выводится табличный конструктор: пользователь заполняет
«Начало формулы» и строки таблицы, а текст формулы собирается автоматически.

## Область применения

| Результат формулы | Поведение |
|---|---|
| `ТипРезультата` содержит `Строка` (шаблоны наименований) | Поле «Формула» **скрыто**; показаны «Начало формулы», переключатель колонки, таблица строк, поле предпросмотра |
| Числовой результат (расчёт цен, планы, финансовые отчёты) | Конструктор скрыт; поле «Формула» видимо и работает по-типовому |

Признак вычисляется `ГКСК_ЭтоСтроковаяФормула()`:
`ТипЗнч(ТипРезультата) = Тип("ОписаниеТипов") И ТипРезультата.СодержитТип(Тип("Строка"))`.

## Состав формы

**Реквизиты**

| Имя | Тип | Назначение |
|---|---|---|
| `ГКСК_НачалоФормулы` | Строка (неограниченная) | Текст в кавычках в начале формулы |
| `ГКСК_СтрокиФормулы` | ТаблицаЗначений | Строки конструктора: `Условие`, `ЕслиЗаполнено`, `ЕслиПусто` (все Строка, неограниченные) |
| `ГКСК_КолонкаВставки` | Строка (20) | Колонка для вставки операнда, если активная ячейка не определена: `Условие` / `ЕслиЗаполнено` / `ЕслиПусто` |
| `ГКСК_Предпросмотр` | Строка (неограниченная) | Итоговая формула (только для чтения) |
| `ГКСК_КонструкторИзменён` | Булево | Пользователь менял конструктор |

**Элементы** (в существующей вертикальной группе `ГруппаФормула`, сверху вниз):
`ГКСК_НачалоФормулы` (поле ввода), `ГКСК_КолонкаВставки` (поле ввода со списком
выбора), `ГКСК_ТаблицаФормулы` (таблица по реквизиту `ГКСК_СтрокиФормулы`) с
колонками `ГКСК_КолонкаУсловие`, `ГКСК_КолонкаЕслиЗаполнено`,
`ГКСК_КолонкаЕслиПусто`, `ГКСК_Предпросмотр` (поле только для чтения), затем
скрываемое типовое поле `Формула`.

Все элементы и форма — `enabled = true`; `ГКСК_Предпросмотр` — `readOnly = true`.

## Сборка формулы

`ГКСК_СобратьФормулу(НачалоФормулы, СтрокиФормулы)` (`&НаКлиентеНаСервереБезКонтекста`):

1. если `СокрЛП(НачалоФормулы) <> ""` — первая часть `"<Начало>"` (в кавычках);
2. для каждой строки с заполненным `Условие` — часть
   `+?(ЗначениеЗаполнено(<Условие>), <ЕслиЗаполнено>, <ЕслиПусто>)`;
   пустая ветка подставляется как `""` (две кавычки);
3. строки без `Условие` пропускаются;
4. части соединяются `Символы.ПС`.

Результат записывается в типовой реквизит `Формула`, поэтому типовые `ОК`,
`Проверить`, `ПередЗакрытием`, `ОперандыФормулы`, `РаботаСФормуламиКлиент.ПроверитьФормулу`
продолжают работать без изменений.

Пересборка вызывается:

- из обработчиков `ПриИзменении` — `ГКСК_НачалоФормулыПриИзменении`,
  `ГКСК_КолонкаУсловиеПриИзменении`, `ГКСК_КолонкаЕслиЗаполненоПриИзменении`,
  `ГКСК_КолонкаЕслиПустоПриИзменении`;
- после вставки операнда или оператора в таблицу;
- перед `ОК`, `Проверить`, `ПередЗакрытием` (`&Перед`-перехватчики
  `ГКСК_ОКПеред`, `ГКСК_ПроверитьПеред`, `ГКСК_ПередЗакрытиемПеред`).

`ГКСК_ПересобратьФормулуПередПроверкой()` пересобирает формулу только если
конструктор видим и (пользователь его менял ИЛИ таблица/начало непусты) — так
форма, открытая с готовой формулой, не затирает её пустым конструктором.

## Вставка операндов и операторов

- `&Вместо("ДеревоОперандовВыбор")` — `ГКСК_ДеревоОперандовВыбор`: при видимом
  конструкторе текст операнда
  (`РаботаСФормуламиКлиентСервер.ПолучитьТекстОперандаДляВставки`) пишется в
  целевую ячейку таблицы, `СтандартнаяОбработка = Ложь`. В остальных случаях
  (числовая формула, неразрешимый операнд) — `ПродолжитьВызов` (типовое поведение).
- `&Вместо("ОператорыВыбор")` — `ГКСК_ОператорыВыбор`: конструкция выбранного
  оператора (`КонструкцияДляВставки`) вставляется в целевую ячейку таблицы;
  группы операторов и нестроковые формулы — `ПродолжитьВызов`.
- Целевая колонка (`ГКСК_КолонкаДляВставки`): активная ячейка таблицы, если
  `Элементы.ГКСК_ТаблицаФормулы.ТекущийЭлемент` — поле одной из трёх колонок;
  иначе — колонка из `ГКСК_КолонкаВставки` (по умолчанию `Условие`).
- Повторный выбор **дописывается** в конец ячейки (можно набрать `" " +` и выбрать
  операнд). Если в таблице нет текущей строки — добавляется новая.

## Прочие изменения поведения

- Кнопка «Вставить условный разделитель» (`ГКСК_ВставитьУсловныйРазделитель`)
  скрыта: она вставляла конструкцию в скрытое поле формулы. Роль разделителя
  выполняет таблица (`+?(ЗначениеЗаполнено(...), " " + ..., "")` собирается сама).
  Группа операторов «Условные разделители» и код команды сохранены.
- Фильтр «Только дополнительные реквизиты» и типовой дерево/палитра операторов
  не менялись.

## Ограничения

- Перетаскивание (drag&drop) операндов и операторов в таблицу не поддерживается —
  вставка выполняется выбором в дереве/палитре.
- Пометка удаления у операнда при вставке в таблицу не запрашивается (вопрос
  остаётся только в типовой ветке `ПродолжитьВызов`).
- Заимствованная форма при обновлении типовой конфигурации требует сверки с
  `BaseForm/Form.form`: базовый модуль обращается к `Элементы.Формула` и
  `ГруппаФормула` — эти элементы не удаляются, поле `Формула` только скрывается.
