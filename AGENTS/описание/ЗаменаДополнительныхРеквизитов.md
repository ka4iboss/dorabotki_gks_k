# Обработка «Замена дополнительного реквизита номенклатуры»

Объект: `DataProcessor.ГКСК_ЗаменаДополнительныхРеквизитов` (подсистема
`ГКСК_ДополнительныйИнструментарий`). Версия подсистемы — `1.2.0`.

## Назначение

Замена одного дополнительного реквизита (свойства ПВХ
`ДополнительныеРеквизитыИСведения`) на другой. Замена выполняется в два этапа:

1. **Вид номенклатуры** — свойство-источник заменяется свойством-приёмником в составе
   набора свойств вида, в настройках вида и в шаблоне рабочего наименования.
2. **Номенклатура** — значения свойства-источника переносятся в свойство-приёмник.

Порядок обязателен: номенклатура при записи читает шаблон и набор свойств из вида.

## Хранилища

- Дополнительные **реквизиты** номенклатуры — табличная часть
  `Справочник.Номенклатура.ДополнительныеРеквизиты` (`Свойство`, `Значение`,
  `ТекстоваяСтрока`).
- Дополнительные реквизиты вида номенклатуры — это состав набора свойств
  `Справочник.НаборыДополнительныхРеквизитовИСведений` (ссылка из реквизита вида
  `НаборСвойств`), табличная часть `ДополнительныеРеквизиты`.
- Дополнительные **сведения** (регистр `ДополнительныеСведения` и табличная часть
  `ДополнительныеСведения` набора) обработкой **не затрагиваются**.

## Этап «Вид номенклатуры»

Для каждого вида номенклатуры, у которого есть что заменять:

1. В наборе свойств (`НаборСвойств`) удаляются строки свойства-источника; если
   свойства-приёмника в наборе ещё нет — добавляется строка приёмника.
2. В семи табличных частях настроек вида (`РеквизитыДляКонтроляНоменклатуры`,
   `РеквизитыДляКонтроляХарактеристик`, `РеквизитыДляКонтроляСерий`,
   `РеквизитыБыстрогоОтбораНоменклатуры`, `РеквизитыБыстрогоОтбораХарактеристик`,
   `РеквизитыХарактеристикДляКлючаЦен`, `РеквизитыСерийДляКлючаЦен`) ссылка
   `Свойство` заменяется на приёмник, `ИмяРеквизита` и `ПредставлениеРеквизита`
   заполняются представлением приёмника.
3. В `ШаблонРабочегоНаименованияНоменклатуры` конструкция
   `{ДР.<ИдентификаторДляФормул источника>}` заменяется на
   `{ДР.<ИдентификаторДляФормул приёмника>}`.

Наборы свойств характеристик и серий (`НаборСвойствХарактеристик`,
`НаборСвойствСерий`) не изменяются. Все изменения вида выполняются в одной
транзакции с блокировкой вида и набора.

## Этап «Номенклатура»

Значения сопоставляются в два консервативных этапа:

1. **Точное** совпадение наименования значения-источника с наименованием значения
   приёмника.
2. **Нормализованное** совпадение: регистр, пробелы, `ё/е`, кавычки, тире и дефисы
   приводятся к пробелу.

Если найдено несколько кандидатов — значение **не заполняется** (статус
«Неоднозначно»), решение принимает пользователь. Ненайденные значения создаются
в иерархическом справочнике приёмника в группе, указанной в строке таблицы
соответствий (наименование и полное наименование берутся из значения-источника
и редактируются).

Принцип: лучше оставить приёмник пустым, чем записать неверное значение.

Перенос значения по номенклатуре:

- если приёмник уже заполнен — строка пропускается с записью в протокол;
- значения-приёмники записываются в строку приёмника (или в новую строку),
  `ТекстоваяСтрока` очищается;
- строки свойства-источника удаляются;
- запись выполняется в транзакции с блокировкой объекта; ошибка одного объекта
  не прерывает обработку.

## Форма

- Параметры: свойство-источник (может быть группой — тогда рекурсивно берутся все
  вложенные свойства-элементы), свойство-приёмник.
- Страница «Значения»: таблица соответствий значений, поле «Группа для создания»
  и кнопка «Заполнить группу у выделенных позиций», кнопка «Найти значения».
- Страница «Виды и номенклатура»: предпросмотр данных (виды и номенклатура),
  кнопка «Показать данные».
- Внизу — кнопка «Выполнить замену» и состояние обработки.

Предпросмотр ограничен 1000 строками по номенклатуре; фоновое выполнение
обрабатывает всё.

## Выполнение

Замена выполняется в фоновом задании через `ДлительныеОперации.ВыполнитьФункцию`
(метод `Обработка.ГКСК_ЗаменаДополнительныхРеквизитов.МодульОбъекта.ВыполнитьЗамену`),
ожидание — `ДлительныеОперацииКлиент.ОжидатьЗавершение`. Результат — протокол
(этап, объект, наименование, свойство-источник, значение, статус, комментарий).

## Ограничения

- Обрабатываются только дополнительные реквизиты (`ЭтоДополнительноеСведение = Ложь`).
- Помеченные на удаление номенклатуры пропускаются.
- Права не обходятся привилегированным режимом: при отсутствии прав на запись
  строка попадает в протокол с ошибкой.
- Выбор группы для создания значений ограничивается владельцем (свойством-приёмником)
  обработчиком `НачалоВыбора`.

## Заимствованные объекты

Для типов реквизитов формы и кода заимствованы:
`ПланВидовХарактеристик.ДополнительныеРеквизитыИСведения`,
`Справочник.ЗначенияСвойствОбъектов`, `Справочник.ЗначенияСвойствОбъектовИерархия`.
Их структура не изменяется.
