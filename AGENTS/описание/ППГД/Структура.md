# Структура подсистемы ППГД расширения «Доработки_ГКС_К»

> **Документ перенесён** из расширения `пустая_для_гкс.РасширениеПраваИПрофилиГруппДоступа`
> в объединённое расширение `Доработки_ГКС_К`; имена объектов приведены к фактическим
> (`ТБ_` / `ппд_` / `пд_` → `ППГД_`). Карта переименований — `описание/Описание.md` §5.

Документ содержит состав объектов подсистемы **«Права»**
(`ППГД_ПраваПрофилейГруппДоступа`, префикс объектов `ППГД_`) и их расположение в файловой
структуре проекта `R:\EDTProjects\GGKKSS\Доработки_ГКС_К`.

Логика работы объектов — в `описание/ППГД/Описание.md`. Общая карта расширения и
переименования при объединении — в корневых `описание/Описание.md` и `описание/Структура.md`
(здесь не дублируются).

## 7. Регистры сведений (`InformationRegisters`)

### `ППГД_ЖурналЗагрузки` (собственный)

- **Файл .mdo:** `src/InformationRegisters/ППГД_ЖурналЗагрузки/ППГД_ЖурналЗагрузки.mdo`
- **Синоним:** Журнал загрузки
- **Измерения:** `ИмяОбъекта` (String 150, mainFilter), `ДатаСобытия` (Date, mainFilter)
- **Ресурс:** `Комментарий` (String)
- **Стандартные:** Active, LineNumber, Recorder, Period
- **`editType`:** `InDialog`; **`dataLockControlMode`:** `Managed`
- **Форма списка:** `ФормаСписка`; **команда:** `ЖурналЗагрузкиПрав`
- **Файл команды:** `src/InformationRegisters/ППГД_ЖурналЗагрузки/Commands/ЖурналЗагрузкиПрав/CommandModule.bsl`

### `ППГД_ПоляВЗапросахМодулей` (собственный)

- **Файл .mdo:** `src/InformationRegisters/ППГД_ПоляВЗапросахМодулей/ППГД_ПоляВЗапросахМодулей.mdo`
- **Синоним:** Поля в запросах модулей (`recordPresentation` — «Поле в запросах модулей»)
- **Измерения:** `Метаданные` (String 200, mainFilter, синоним «Объект метаданных») — полное имя
  объекта метаданных; `Поле` (String 200, mainFilter) — имя поля, в том числе `<ТЧ>.<Реквизит>` и `*`
- **Ресурсы:** `КоличествоЗапросов` (Number, precision 10); `СписокМодулей` (String) — до 20
  путей модулей относительно корня выгрузки через `; `
- **Стандартные:** Active, LineNumber, Recorder, Period
- **`editType`:** `InDialog`; **`dataLockControlMode`:** `Managed`; **`useStandardCommands`:** `true`
- **Назначение:** результат анализа текстов модулей (обработка `ППГД_АнализЗапросовМодулей`,
  общий модуль `ППГД_АнализЗапросовСервер`); источник данных для группировки ролей
  «по полям запросов» в `ППГД_ПодборРолейДляПрофиляГруппДоступа`
