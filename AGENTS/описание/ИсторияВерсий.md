# История версий расширения «Доработки_ГКС_К»

Сводная хроника изменений версий объединённого расширения. Собрана из
документации двух исходных расширений (`пустая_для_гкс.ГКС_Инструкции` и
`пустая_для_гкс.РасширениеПраваИПрофилиГруппДоступа`), перенесённой в этот
проект. Канонические описания архитектуры — в `Описание.md`, `Структура.md` и
описаниях подсистем; здесь фиксируется только история версий.

> **Об источнике.** Git-репозитория в проекте нет; история восстановлена из
> markdown-документации. Текущая версия сверена с
> `src/Configuration/Configuration.mdo` (`<version>1.0.1.0</version>`).
> Имена объектов приведены к фактическим именам объединённого расширения
> (см. `Описание.md` §5): `ТБ_*`/`ппд_*`/`пд_*` → `ППГД_*`, `РМ_*` → `ГКСИ_*`.

## Текущая версия

**`1.0.5.1`** — файл `src/Configuration/Configuration.mdo`.

## Правило версионирования

Каноническое описание схемы — в **`Версионирование.md`** (этот файл — только хроника).

Кратко: версия расширения в `Configuration.mdo` — четыре числа
`major расширения . major подсистем . minor подсистем . patch подсистем` (старт `1.0.0.0`);
версии подсистем (независимые `major.minor.patch`) — в общем модуле `ГКСК_Версии`
(`ВерсияГКСИ()` — старт `2.35.1`, `ВерсияППГД()` — старт `1.20.3`,
`ВерсияВерсииОбъектов()` — старт `1.0.0`, `ВерсияШаблоновНаименований()` — старт `1.0.0`,
`ВерсияРасширения()`, `Версии()`). Порядок выпуска:
(1) версия изменившейся подсистемы → (2) версия расширения → (3) запись в таблице ниже.

## Правила ведения этого файла

1. **После изменения версии расширения** — обязательно дописывать сюда короткую
   запись: новый номер версии → что изменено (1–3 предложения) → тип
   (фича / багфикс / рефакторинг). Ссылка на подробный отчёт — в колонке «Источник».
2. **Любое значимое изменение** (даже без смены версии) — желательно фиксировать
   здесь же.
3. Новые записи добавлять в конец соответствующего раздела (по возрастанию версии).
4. Если обнаруживается расхождение номеров между отчётами — вносить в раздел
   «Противоречия в документации», а не «исправлять» молча.
