# Структура подсистемы «ВерсииОбъектов»

Карта объектов подсистемы и их расположения в файловой структуре проекта `Доработки_ГКС_К`.
Архитектура и логика — в `Описание.md`.

## 1. Объекты метаданных

| Объект | Тип | Файл |
|---|---|---|
| `ГКСК_ВерсииОбъектов` | Подсистема | `src/Subsystems/ГКСК_ВерсииОбъектов/ГКСК_ВерсииОбъектов.mdo` |
| `ГКСК_ПросмотрВерсийОбъектов` | Обработка | `src/DataProcessors/ГКСК_ПросмотрВерсийОбъектов/ГКСК_ПросмотрВерсийОбъектов.mdo` |
| `ГКСК_ПросмотрВерсийОбъектов.Форма.Форма` | Форма обработки | `src/DataProcessors/ГКСК_ПросмотрВерсийОбъектов/Forms/Форма/Form.form` |
| Модуль формы | Модуль | `src/DataProcessors/ГКСК_ПросмотрВерсийОбъектов/Forms/Форма/Module.bsl` |
| `ГКСК_ВерсииОбъектовСервер` | Общий модуль (Сервер) | `src/CommonModules/ГКСК_ВерсииОбъектовСервер/ГКСК_ВерсииОбъектовСервер.mdo` |
| Модуль общего модуля | Модуль | `src/CommonModules/ГКСК_ВерсииОбъектовСервер/Module.bsl` |
| `ВидыНоменклатуры` | Справочник (заимствован) | `src/Catalogs/ВидыНоменклатуры/ВидыНоменклатуры.mdo` |

Состав подсистемы `ГКСК_ВерсииОбъектов` (содержимое): обработка `ГКСК_ПросмотрВерсийОбъектов`,
общий модуль `ГКСК_ВерсииОбъектовСервер`. Справочник `ВидыНоменклатуры` заимствован в расширение
для поля отбора по виду номенклатуры (в подсистему не включён).

## 2. Программный интерфейс общего модуля

| Метод | Назначение |
|---|---|
| `ВерсионируемыеОбъекты()` | Список типов, версионируемых любым механизмом (версионирование объектов и история данных): ТипОбъекта, ПолноеИмя, Представление. |
| `ВидСпискаТипаОбъекта(ТипОбъекта)` | Вид списка данных типа: `Ссылки`, `ЗаписиРегистра` или пустая строка. |
| `СписокОбъектовТипа(ТипОбъекта, СтрокаПоиска, ВидНоменклатуры, Максимум)` | Объекты типа с количеством пользовательских версий; отбор по виду номенклатуры (таблица значений). |
| `СписокЗаписейРегистра(ТипОбъекта, СтрокаПоиска, Максимум)` | Записи регистра сведений, у которых есть версии истории данных: `{Отметка, Запись, Наименование}`. |
| `ДанныеПоЗаписиСтрокой(ТипОбъекта, ЗаписьСтрокой)` | Восстановление ключа записи регистра из упакованного значения. |
| `НастройкиДинамическогоСпискаОбъектов(ТипОбъекта, СтрокаПоиска, ВидНоменклатуры)` | Настройки динамического списка объектов: основная таблица, текст запроса с полями `Ссылка`/`Наименование`, значения параметров отбора. |
| `ЕстьРеквизитВидНоменклатуры(ТипОбъекта)` | Признак наличия реквизита `ВидНоменклатуры` у типа объекта. |
| `СведенияОВерсиях(Данные)` | Структура `{Текущая, Прошлая, Первая, Источник}` со сведениями о версиях. |
| `ТаблицаРазличийВерсий(Данные)` | Сводная таблица различий реквизитов по трём версиям. |
| `НомераВерсийПоТипу(СписокОбъектов, ТипВерсии)` | Соответствие «объект → номер версии указанного вида» (один запрос на механизм). |
| `НомераВерсийЗаписейПоТипу(ТипОбъекта, СписокЗаписей, ТипВерсии)` | Соответствие «ключ записи → номер версии указанного вида». |
| `НомерВерсииПоТипу(Данные, ТипВерсии)` | Номер версии указанного вида для одних данных. |
| `ПерейтиНаВерсию(Данные, НомерВерсии, ТекстСообщенияОбОшибке, Источник)` | Переход на версию выбранным механизмом; возвращает статус перехода. |
| `ОтчетПоВерсии(Данные, НомерВерсии)` | Печатная форма данных по версии. |
| `ЕстьПравоПереходаНаВерсию()` | Признак наличия права перехода на версию. |
| `ВыполнитьПереходНаВерсииДляОтмеченных(Параметры, АдресРезультата)` | Фоновая процедура пакетного перехода (для длительной операции). |

Служебные функции (не экспортные): `НомераВерсийПользователя`, `НомерВерсииИзСписка`,
`СведенияОЗаписиВерсии`, `СведенияОЗаписиВерсииИсторииДанных`, `ПредставлениеВерсии`,
`ПредставлениеВерсииИсторииДанных`, `РеквизитыВерсии`, `РеквизитыВерсииПоИсточнику`,
`РеквизитыВерсииИсторииДанных`, `ОтчетПоВерсииИсторииДанных`,
`ПредставлениеЗначенияРеквизита`, `ВсеЗначенияРавны`, `ПолноеИмяТипаОбъекта`,
`ВыражениеНаименованиеОбъекта`, `ПредставлениеТипаОбъекта`, `ЭтоВерсионируемыйТипОбъекта`,
`ЭтоТипСИсториейДанных`, `ЭтоОбъектМетаданныхСИсториейДанных`, `ОбъектыМетаданныхСИсториейДанных`,
`ДобавитьОбъектыМетаданныхСИсториейДанных`, `ЗаполнитьТипыВерсионированияОбъектов`,
`ЗаполнитьТипыИсторииДанных`, `ВерсииИсторииДанныхПоМетаданным`, `ВерсииИсторииДанныхПоДанным`,
`ЗаполнитьСведенияОВерсияхИсторииДанных`, `НомераВерсийИсторииДанных`, `НомераВерсийОбъектов`,
`ВерсияВВерсияхОбъектов`, `ВосстановитьВерсиюИсторииДанных`, `ЗначенияКлючаЗаписи`,
`ЗаписьСтрокойКлючаЗаписи`, `ИсточникиВерсийОбъектов`, `ВыполнитьПереходНаВерсииОбъектов`,
`ВыполнитьПереходНаВерсииЗаписейРегистра`, `ОбъектМетаданныхПоТипуОбъекта`,
`ОбъектМетаданныхВерсионируемогоТипа`, `ИмяСтандартногоРеквизита`,
`ВыражениеПометкиУдаленияОбъекта`, `ЗаполнитьКоличествоВерсий`,
конструкторы таблиц `НоваяТаблицаТиповОбъектов` / `НоваяТаблицаОбъектов` / `НоваяТаблицаЗаписейРегистра` / `НоваяТаблицаРазличий`.

## 4. Используемые объекты основной конфигурации

| Объект | Использование |
|---|---|
| `РегистрСведений.ВерсииОбъектов` | Чтение версий (измерения `Объект`, `НомерВерсии`; реквизиты `ДатаВерсии`, `АвторВерсии`, `Комментарий`, `ТипВерсииОбъекта`). |
| `РегистрСведений.НастройкиВерсионированияОбъектов` | Определение типов объектов с включённым версионированием. |
| `Справочник.ИдентификаторыОбъектовМетаданных` | Идентификаторы типов объектов и их полные имена. |
| `Справочник.ВидыНоменклатуры` | Отбор номенклатуры по виду; справочник заимствован в расширение. |
| `Перечисление.ТипыВерсийОбъекта` | Отбор пользовательских версий (`ИзмененоПользователем`). |
| Общий модуль `ВерсионированиеОбъектов` | `НомерПоследнейВерсии`, `РазборВерсии`, `ПерейтиНаВерсиюСервер`, `ОтчетПоВерсииОбъекта`, `ЕстьПравоЧтенияИнформацииОВерсияхОбъектов`. |
| Глобальный контекст `ИсторияДанных` | Платформенная история данных: `ВыбратьВерсии`, `ПолучитьДанныеВерсии`, `СформироватьПоВерсии`. |
| Свойство метаданных `ИсторияДанных` (тип `ИспользованиеИсторииДанных`) | Определение объектов метаданных с включённой историей данных. |
| Общий модуль `ОбщегоНазначения` | `ОбъектМетаданныхПоИдентификатору`, `ОбъектыМетаданныхПоИдентификаторам`, `ИдентификаторОбъектаМетаданных`, `МенеджерОбъектаПоПолномуИмени`, `ЗначениеСсылочногоТипа`. |
| Общий модуль `ОбработкаОшибок` | `ПодробноеПредставлениеОшибки` при восстановлении версии истории данных. |
| Общий модуль `ДлительныеОперации` (+`ДлительныеОперацииКлиент`) | Асинхронный пакетный переход. |
| Общий модуль `Пользователи` | `ЭтоПолноправныйПользователь()`. |
| Общий модуль `СтандартныеПодсистемыКлиент` | Вывод информации об ошибке фонового задания. |

## 5. Версия подсистемы

Версия подсистемы ведётся в общем модуле `ГКСК_Версии` (`ВерсияВерсииОбъектов()`),
текущее значение — `1.3.0`. Схема — `../Версионирование.md`.
