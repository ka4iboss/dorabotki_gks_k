# ОТЧЁТ — Выравнивание текста относительно картинок в сохранённом HTML сценария

## Задача

При вставке картинки и текста в одну строку Markdown-описания сценария
(`![alt](Код) текст`) текст в **сохранённом** HTML-файле отображался
прижатым к низу картинки. Нужно, чтобы текст выравнивался по центру картинки
(либо по верху — на выбор пользователя).

## Причина

Сохранённый присоединённый HTML-файл сценария собирается **без CSS**:

```
<html><meta charset="UTF-8"><body>…HTML от showdown…</body></html>
```

`<img>` по умолчанию имеет `vertical-align: baseline` — низ картинки
встаёт на базовую линию текста, поэтому текст «прилипает» к низу изображения.

В предпросмотре формы текст уже центрируется правилом
`div.wiki img { vertical-align: middle; }` (CSS из
`ГКСИ_MarkdownСерверВызовСервера.СформироватьТекстHTMLДляТекстаMarkdown`,
контент обёрнут в `<div class="wiki">`), а в сохранённом файле такого
правила не было — отсюда расхождение «в форме нормально, в файле нет».

## Решение

Файл: `src/CommonModules/ГКСИ_MarkdownФормаКлиент/Module.bsl`,
процедура `ЗаписатьHTMLИзMarkdown` (общая точка записи и для элемента, и для
группы справочника `ДемонстрационныеСценарии`).

После `ДемонстрационныеСценарииКлиентСервер.ДобавитьТегиТелаЕслиНеобходимо`
в готовый HTML добавляется инлайновый `<style>`:

```bsl
ФрагментHTML = СтрЗаменить(ФрагментHTML, "<body>",
	"<body><style>img { vertical-align: middle; }</style>");
```

`<body>` в этот момент гарантированно есть: `ДобавитьТегиТелаЕслиНеобходимо`
добавляет его, если тега не было (showdown-фрагмент тегов документа не содержит).

Выбрано `middle` (центр) — чтобы сохранённый файл совпадал с предпросмотром
формы. Смена на выравнивание по верху — замена `middle` на `top` в этой строке.

## Почему одна точка правки достаточна

И форма элемента, и форма группы делегируют запись в одну процедуру:

- `Catalogs/ДемонстрационныеСценарии/Forms/ФормаЭлемента/Module.bsl`,
  `РМ_КлиентскийПередЗаписью` → `ГКСИ_MarkdownФормаКлиент.ЗаписатьHTMLИзMarkdown`;
- `Catalogs/ДемонстрационныеСценарии/Forms/ФормаГруппы/Module.bsl`,
  `РМ_ЗаписатьHTMLИзMarkdown` → та же процедура.

Дальше HTML идёт и по пути создания файла, и по пути перезаписи существующего
(`ГКСИ_MarkdownФормаСервер.СоздатьПрисоединенныеФайлыИзДопСвойств`), потому что
оба получают уже готовый `ФрагментHTML` из `ДополнительныеСвойства` / `ПараметрыЗаписи`.

Локальная `РМ_ЗаписатьHTMLИзMarkdown` в модуле `ФормаЭлемента` (строка ~703) —
мёртвый дубль той же логики, нигде не вызывается; не тронута.
