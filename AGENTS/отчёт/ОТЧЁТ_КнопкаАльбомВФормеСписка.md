# Отчёт: кнопка «Альбом процессов» в форме списка + фикс `СортироватьПоЗначению`

## Цель

1. Исправить runtime-ошибку в `ГКСИ_АльбомПроцессов.КодыЯзыковКонфигурации()`
   (метод `СортироватьПоЗначению()` вызывался на `Массив`).
2. Добавить команду «Альбом процессов» в командную панель дерева
   `ФормаСпискаДеревоГрупп` для формирования альбома по выделенным группам.

## Что сделано

### Шаг 0. Bugfix `КодыЯзыковКонфигурации`

Файл: `src/CommonModules/ГКСИ_АльбомПроцессов/Module.bsl`.

Заменён `Массив.СортироватьПоЗначению()` (метода нет) на сортировку через
`СписокЗначений.СортироватьПоЗначению()` с последующей конвертацией в
`Массив`. Публичная сигнатура `Экспорт` сохранена.

### Шаг 1. Форма `АльбомПроцессов` принимает параметр

Файл: `src/Catalogs/ДемонстрационныеСценарии/Forms/АльбомПроцессов/Module.bsl`.

В `&Перед("ПриСозданииНаСервере")` добавлена проверка `Параметры.Свойство("ГруппыДляАльбома")`:
- если параметр — массив, вызывается `СобратьДокументАльбомаПоГруппам(...)`;
- иначе (форма открыта «сама по себе») — `СобратьДокументАльбома()`.

### Шаг 2. Команда и кнопка в `ФормаСпискаДеревоГрупп`

Файл: `src/Catalogs/ДемонстрационныеСценарии/Forms/ФормаСпискаДеревоГрупп/Form.form`.

Через `1C_EditMetadata`:
- `addFormCommand` — добавлена команда `АльбомПоВыделенным` с заголовком
  «Альбом процессов» и обработчиком `АльбомПоВыделенным` в модуле;
- `addFormButton` — добавлена кнопка `ГКСИ_ДеревоСценариевАльбомПроцессов`
  в командную панель формы `ФормаКоманднаяПанель` (рядом с
  `ПометитьНаУдаление`).

### Шаг 3. Обработчик команды + серверная функция

Файл: `src/Catalogs/ДемонстрационныеСценарии/Forms/ФормаСпискаДеревоГрупп/Module.bsl`.

Добавлены:

| Процедура / функция | Назначение |
|---|---|
| `АльбомПоВыделенным(Команда)` (`&НаКлиенте`) | Собирает массив групп из выделенных строк, открывает `АльбомПроцессов` с параметром `ГруппыДляАльбома`. |
| `ГКСИ_ГруппыДляАльбомаПоВыделению()` (`&НаКлиенте`) | Оркестратор: вызывает разбор выделения, при наличии элементов — серверный запрос групп, склеивает с дедупликацией. |
| `ГКСИ_РазделитьВыделениеПоГруппам(МассивГрупп, МассивЭлементов, Дедупликация)` (`&НаКлиенте`) | Разделяет выделенные строки по типу (`ЭтоГруппа` = Истина/Ложь). Выделено в отдельную процедуру для снижения когнитивной сложности. |
| `ГКСИ_ПолучитьГруппыСценариевНаСервере(Знач МассивСценариев)` (`&НаСервереБезКонтекста`) | Один пакетный запрос к РС `ГКСИ_ГруппыСценариев`: `ВЫБРАТЬ РАЗЛИЧНЫЕ Группа ГДЕ Сценарий В(&Сценарии)`. |

`Знач` в параметре серверной функции добавлен по требованию линтера
(`TransferringParametersBetweenClientAndServer`).

## Ручная проверка (для оператора)

| Действие | Ожидание |
|---|---|
| Ничего не выделено → нажать «Альбом процессов» | Альбом по всем корневым группам |
| Выделена одна группа | Альбом по её поддереву |
| Выделено несколько групп | Альбом по их объединению |
| Выделены только элементы | Альбом по группам, в которые входят эти элементы (через РС) |
| Выделены и группы, и элементы | Альбом по объединению (с дедупликацией) |
| Открыть `АльбомПроцессов` из формы группы | Альбом по всем группам (старое поведение) |
