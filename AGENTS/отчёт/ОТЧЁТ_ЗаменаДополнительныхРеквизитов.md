# Отчёт: обработка «Замена дополнительного реквизита номенклатуры»

Дата: 2026-11-18. Версия расширения: `1.0.22.0` (minor подсистемы `ДополнительныйИнструментарий`,
`1.1.1` → `1.2.0`). Тип: фича.

## Что сделано

Создана обработка `DataProcessor.ГКСК_ЗаменаДополнительныхРеквизитов` с формой `Форма`.

Состав:

- `ObjectModule.bsl` — разворот группы свойств в список элементов, проверка пары свойств,
  сопоставление значений (точное и нормализованное наименование), создание недостающих
  значений в иерархии приёмника, предпросмотр, замена в виде номенклатуры (набор, семь
  табличных частей настроек, шаблон рабочего наименования), перенос значений номенклатуры,
  чтение результата из временного хранилища.
- `Forms/Форма` — страницы «Значения» и «Виды и номенклатура», поля выбора свойств и группы
  создания, таблицы соответствий и предпросмотра, кнопки у своих таблиц, состояние обработки.
- Фон — `ДлительныеОперации.ВыполнитьФункцию` + `ДлительныеОперацииКлиент.ОжидатьЗавершение`.

## Решения

- Замена выполняется в два этапа: сначала вид номенклатуры, затем номенклатура.
- Конфликт у номенклатуры (приёмник заполнен) — пропуск с протоколом.
- Значения-источники после переноса удаляются; само свойство не помечается.
- Сопоставление только точное и нормализованное; неоднозначные значения не заполняются.
- Дополнительные сведения не обрабатываются.
- Наборы свойств характеристик и серий не изменяются.
- Шаблоны: только `ШаблонРабочегоНаименованияНоменклатуры`.

## Заимствования

`ПланВидовХарактеристик.ДополнительныеРеквизитыИСведения`,
`Справочник.ЗначенияСвойствОбъектов`, `Справочник.ЗначенияСвойствОбъектовИерархия` —
нужны для типов реквизитов формы и кода; структура не изменялась.

## Проверка

- `GetMarkers` по объекту и модулям: ошибок нет; остаются предупреждения EDT
  `SU71`/`SU239`/`SU234`/`SU29` (ложноположительные для заимствованных объектов и
  реквизитов формы типа ТаблицаЗначений).
- Созданное значение пишется напрямую в `Справочники.ЗначенияСвойствОбъектовИерархия`
  (или `ЗначенияСвойствОбъектов` по типу свойства), без вызова БСП `УправлениеСвойствами`.
