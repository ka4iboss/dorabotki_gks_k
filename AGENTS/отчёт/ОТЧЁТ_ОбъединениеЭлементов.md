# Отчёт: обработка «Объединение элементов» (`ГКСК_ОбъединениеЭлементов`)

- **Дата:** 2026-10-29
- **Версия расширения:** `1.0.18.1` → `1.0.19.0` (minor подсистем)
- **Подсистема:** `ГКСК_ДополнительныйИнструментарий` (новая, `1.0.0`)
- **Тип изменения:** фича

## 1. Задача

Сделать обработку, аналогичную типовой `Обработка.ПоискИУдалениеДублей`, но без
автоматического поиска дублей: пользователь сам выбирает, что с чем объединять
(«любой элемент на любой» в рамках одного объекта метаданных и владельца).
Объединение = выбор оригинала и дублей → поиск мест использования → замена ссылок
дублей на ссылку оригинала во всех местах использования.

## 2. Что сделано

### 2.1 Метаданные

| Объект | Назначение |
|---|---|
| `Subsystem.ГКСК_ДополнительныйИнструментарий` | новая подсистема верхнего уровня; в неё вложена `ГКСК_ВерсииОбъектов` |
| `DataProcessor.ГКСК_ОбъединениеЭлементов` | обработка (форма `Форма`) |
| `CommonModule.ГКСК_ОбъединениеЭлементовСервер` | серверная логика (серверный, вне клиентских вызовов) |

### 2.2 Форма

Реквизиты: `СписокЭлементов` (динамический список, произвольный запрос),
`ОтмеченныеДубли` (СписокЗначений — создаётся в `ПриСозданииНаСервере`),
`ОригиналСтрокой`, `ИмяОбъекта`, `СпособУдаления`,
`Состояние`, `ОригиналПредставление`,
`СводкаМестИспользования` (таблица значений: `Представление`, `МестИспользования`).

Элементы: поле ввода объекта метаданных `ПолеОбъектаМетаданных` (привязано к
`ИмяОбъекта`, выбор по `НачалоВыбора` → `ПоказатьВыборИзСписка`; при открытии пустое),
надписи оригинала и состояния, поле способа удаления дублей (выбор из списка:
«Пометка на удаление» / «Непосредственное удаление», по умолчанию — пометка),
таблица `СписокЭлементов` (Код,
Наименование, ПометкаУдаления, ЭтоОригинал, ЭтоДубль, КудаОбъединять) и таблица
`ТаблицаМестИспользования`.

Команды: `ОтметитьОригинал`, `ОтметитьДубли`, `СнятьОтметки`,
`ПоказатьМестаИспользования`, `РассчитатьМестаИспользования`, `Объединить`.

Запрос динамического списка (произвольный, параметры `&Оригинал`, `&ОтмеченныеДубли`):

```
ВЫБРАТЬ
    Таблица.Ссылка КАК Ссылка,
    Таблица.Код КАК Код,
    Таблица.Наименование КАК Наименование,
    Таблица.ПометкаУдаления КАК ПометкаУдаления,
    ВЫБОР КОГДА Таблица.Ссылка = &Оригинал ТОГДА ИСТИНА ИНАЧЕ ЛОЖЬ КОНЕЦ КАК ЭтоОригинал,
    ВЫБОР КОГДА Таблица.Ссылка В (&ОтмеченныеДубли) ТОГДА ИСТИНА ИНАЧЕ ЛОЖЬ КОНЕЦ КАК ЭтоДубль,
    ВЫБОР КОГДА Таблица.Ссылка В (&ОтмеченныеДубли) ТОГДА &Оригинал КОНЕЦ КАК КудаОбъединять
ИЗ Справочник.Номенклатура КАК Таблица
```

Текст запроса формируется `ГКСК_ОбъединениеЭлементовСервер.ТекстЗапросаСписка(ИмяОбъекта)`.

### 2.3 Логика

- `ОбъектыДляВыбора()` — перечень справочников/ПВХ/планов счетов/планов видов
  расчёта, доступных по функциональным опциям.
- `ОпределитьМестаИспользованияФон` → `ОбщегоНазначения.МестаИспользования`
  (привилегированный режим), свёртка по `Ссылка` с количеством вхождений.
- `ПроверитьНабор` — один объект метаданных, один владелец, не группы.
- `ПроверитьВозможностьЗамены` → `ОбщегоНазначения.ВозможностьЗаменыЭлементов`.
- `ЗаменитьСсылкиФон` → `ОбщегоНазначения.ЗаменитьСсылки` с последующей пометкой
  дублей на удаление (способ удаления — с формы).
- Оба длительных шага запускаются через `ДлительныеОперации.ВыполнитьВФоне`
  с ожиданием на клиенте и оповещениями; в форме нет длительных синхронных вызовов.

## 3. Валидация

- `ГКСК_ОбъединениеЭлементовСервер/Module.bsl` — 0 маркеров 1С.
- `DataProcessors/ГКСК_ОбъединениеЭлементов/Forms/Форма/Module.bsl` — 0 маркеров.
- `Form.form`, `ГКСК_ДополнительныйИнструментарий.mdo` — 0 маркеров.
- Убраны по ходу: SU13 (обёртка над `ОбщегоНазначения.ПараметрыПоискаМестИспользования`
  удалена, вызов прямой), SU58, SU78, SU83, SU118 (поле «Ссылка» в таблице динсписка
  не выводится), SU234 (замена `СписокВыбора` у поля ввода на реквизит
  `ДоступныеОбъекты` типа СписокЗначений), SU66/SU72/SU93 (стандартные области модуля).

## 4. Ограничения

- Объединение только внутри одного объекта метаданных и одного владельца; группы
  справочников не объединяются (как в типовой).
- Замена ссылок на документы не поддерживается (выбраны справочники, ПВХ, планы).
- Замена выполняется средствами БСП: правила `ОбщегоНазначения.ЗаменитьСсылки`
  соблюдаются, включая короткие транзакции и обработку ошибок по объектам.
