# ОТЧЁТ_ПозицияВнутриГруппы

## Что сделано

Изменён алгоритм формирования ресурса `ПолныйКодКонтекстный` регистра сведений `ГКСИ_ГруппыСценариев`: вторая и последующие позиции в пути обозначают **порядковый номер члена внутри его непосредственной родительской группы**, а не системный код справочника. Обеспечено отображение контекстного кода для **вложенных групп** в форме списка `ФормаСпискаДеревоГрупп` — раньше для групп показывался только их системный код.

Миграция старых записей регистра **не поддерживается** — пользователь вручную очищает справочник `ДемонстрационныеСценарии` и регистр `ГКСИ_ГруппыСценариев` и перезагружает сценарии обработкой `ГКСИ_ЗагрузкаСценариевИзMarkdown`.

## Формат кода

```
Корневая группа 001           →  "001"
├─ Элемент A (системный 002)  →  "001.001"
├─ Элемент B (системный 003)  →  "001.002"
└─ Подгруппа X (системный 010)→  "001.003"
   └─ Элемент C (системный 011) → "001.003.001"

Корневая группа 002           →  "002"
├─ Элемент D (системный 004)  →  "002.001"
└─ Элемент E (системный 005)  →  "002.002"
```

Правила:

- Для **корневой группы** (без родителя в регистре) используется её собственный системный `Код`.
- Для **вложенной группы или элемента** используется **позиция среди сиблингов родительской группы**: прямые дети родителя сортируются по системному `Код` ASC, и члену присваивается его индекс в этом отсортированном списке (`ЧЦ=3; ЧВН=`, например `001`, `017`).
- Подгруппы и обычные элементы **делят общий счётчик** внутри родительской группы.

## Технические замечания

- **Длина позиции** — `Формат(Индекс, "ЧЦ=3; ЧВН=")`. Если в группе окажется более 999 прямых членов (элементов и подгрупп суммарно), формат `ЧЦ=3; ЧВН=` выведет 4+ цифр естественным образом. Если это станет проблемой — расширить формат до `ЧЦ=4` (потребуется увеличить длину ресурса `ПолныйКодКонтекстный`).
- **Сортировка** лексикографическая по строковому `Код`. Так как справочник имеет фиксированную длину кода с ведущими нулями, `"002" < "010" < "100"` работает корректно. Используется `СписокЗначений.СортироватьПоПредставлению()` (документирован с 8.0).
- **Файлы присоединённых HTML-описаний** не зависят от нового формата (`ИмяФайлаОписанияСценария` берёт `УникальныйИдентификатор()`), миграция файлов не требуется.
- **Циклы в иерархии** защищены существующим `Обработанные` в `ПолныйКодВКонтекстеГрафа` — алгоритм обхода вверх останавливается при повторном посещении узла.
- **Множественная принадлежность**: у группы с несколькими родителями в регистре несколько записей `ПолныйКодКонтекстный` (по одной на каждого родителя). В форме списка для корневой строки группы показывается один (первый встреченный). Это совпадает с поведением старого кода.
- **Поиск индекса в `ГКСИ_ПозицияСиблингаГрафа`** — реализован ручным перебором `СписокЧленов[Сч].Значение = ЧленГруппы`. Не через `СписокЗначений.НайтиПоЗначению`: согласно документации платформы, `НайтиПоЗначению` возвращает `ЭлементСпискаЗначений` (а не индекс), и попытка использовать результат как число даёт ошибку приведения. На первой итерации это всплыло как «Преобразование значения к типу Число не может быть выполнено» при открытии формы элемента/группы и как «пустой код у групп / одинаковые коды» — потому что исключение ломало пересчёт всего поддерева.
- **Маркеры EDT**: после правок добавлены только стилистические предупреждения (SU29 `Соответствие` без типа элемента, SU72 неэкспортная функция в служебной области) — оба устоявшихся паттерна проекта, не блокируют и не относятся к ошибкам.
- **`ГКСИ_ПолныйКодПоГрафу`** теперь стала тонкой обёрткой над `ПолныйКодВКонтекстеГрафа` (бывшая копия). Используется в `ПересчитатьПолныйКодКонтекстныйДляСценария` и `ПересчитатьПолныйКодДляПоддереваГрафа`.

## Как проверять

1. Открыть форму списка `ДемонстрационныеСценарии` (`ФормаСпискаДеревоГрупп`):
   - У корневых групп в колонке «ПолныйКодКонтекстный» — их собственный код (`001`).
   - У элементов внутри корневой группы — контекстный код вида `001.001`, `001.002`, …
   - У подгруппы — `001.NNN`. У элементов внутри подгруппы — `001.NNN.MMM`.
2. Открыть форму элемента/группы — панель «Входит в группы» показывает те же контекстные коды.
3. Открыть «Альбом процессов» — заголовки `h2`/`h3` упорядочены по возрастанию контекстного кода.
4. Создать новый элемент внутри существующей группы — его позиция в счётчике пересчитывается автоматически через `ГКСИ_ГруппыСценариевСервер.ПересчитатьПолныйКодДляПоддерева`.
