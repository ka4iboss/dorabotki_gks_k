# Отчёт: обработка «Групповое изменение записей регистров сведений»

## Задача

Типовая обработка `Обработка.ГрупповоеИзменениеРеквизитов` не умеет править регистры
накопления и сведений: она построена на ссылочных объектах (`Ссылка`, `ПолучитьОбъект()`).
По решению пользователя сделана отдельная обработка расширения, а не заимствование
типовой (чтобы не заимствовать пять её форм и не зависеть от обновлений).

## Объект

`DataProcessor.ГКСК_ГрупповоеИзменениеЗаписейРегистров`
(подсистема `ГКСК_ДополнительныйИнструментарий`, префикс `ГКСК_`).

Состав:

- `ObjectModule.bsl` — серверная логика: список полей регистра, построение запроса
  отбора, фоновое изменение записей, результат по каждой записи.
- `Forms/Форма` — управляемая форма: выбор регистра, таблица полей с флажком
  «Изменять» и новым значением, таблица условий отбора, прогресс и таблица результата.

## Логика

1. Пользователь выбирает регистр сведений (список всех `Метаданные.РегистрыСведений`).
2. Форма заполняет поля регистра: `Регистратор` (для подчинённых), `Период`
   (для периодических), измерения, ресурсы, реквизиты.
3. Отбор задаётся таблицей условий: поле, вид сравнения (`Равно`, `НеРавно`,
   `Больше`, `БольшеИлиРавно`, `Меньше`, `МеньшеИлиРавно`, `Содержит`,
   `НачинаетсяС`, `Заполнено`, `НеЗаполнено`), значение. Имена полей проверяются
   по метаданным регистра, значения передаются параметрами запроса.
4. Изменение выполняется в фоновом задании
   (`ДлительныеОперации.ВыполнитьВФоне` + `ДлительныеОперацииКлиент.ОжидатьЗавершение`).
5. Для **независимого** регистра используется `РегистрСведенийМенеджерЗаписи`:
   запись читается по ключу, изменения применяются и записываются. Если изменились
   измерения или период, старая запись удаляется, а новая пишется с новым ключом
   (перед этим проверяется, что запись с новым ключом не существует).
6. Для **подчинённого регистратору** регистра менеджер записи недоступен: читается
   набор записей по регистратору, нужная строка находится по ключу, изменения
   применяются, набор записывается с замещением. Запись выполняется с
   `ОбменДанными.Загрузка = Истина`.
7. Каждая запись обрабатывается в отдельной транзакции; ошибки не прерывают
   обработку, а попадают в таблицу результата (запись + текст ошибки).

## Ограничения и предупреждения

- Для подчинённых регистратору регистров изменения будут потеряны при перепроведении
  документа-регистратора — форма показывает предупреждение перед запуском.
- Поле `Регистратор` не изменяется (ключ подчинённого регистра).
- Значения вводятся в колонку произвольного типа и приводятся к типу поля регистра
  через `ОписаниеТипов.ПривестиЗначение`; для ссылочных типов удобнее выбирать значение
  из поля ввода.
- `Заполнено`/`НеЗаполнено` проверяют `NULL` в запросе.
