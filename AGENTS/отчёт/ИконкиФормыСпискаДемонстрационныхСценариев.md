# Иконки на форме списка справочника «Демонстрационные сценарии»

## Назначение

Описание того, как на форме списка `ФормаСпискаДеревоГрупп` отрисовываются иконки слева от наименования (папка/элемент, с ветвлением и без, с пометкой удаления и без).

Используется стандартный механизм платформы: свойство таблицы формы **`rowsPicture`** (общая картинка-коллекция) + числовое поле `Картинка` в строке дерева значений, задающее индекс картинки в коллекции.

## Где задаётся

Файлы:
- `src/Catalogs/ДемонстрационныеСценарии/Forms/ФормаСпискаДеревоГрупп/Form.form` — структура формы. У **таблицы** `ГКСИ_ДеревоСценариев` указано `<rowsPicture>` со ссылкой на `CommonPicture.ПиктограммыЭлементов`.
- `src/Catalogs/ДемонстрационныеСценарии/Forms/ФормаСпискаДеревоГрупп/Module.bsl` — расчёт индекса картинки в строке дерева (`ГКСИ_ИндексКартинкиГруппы`, `ГКСИ_СоздатьУзелСценария`).

Ключевой фрагмент `Form.form` (таблица `ГКСИ_ДеревоСценариев`):
```xml
<items xsi:type="form:Table">
  <name>ГКСИ_ДеревоСценариев</name>
  <rowPictureDataPath xsi:type="form:DataPath">
    <segments>ГКСИ_ДеревоСценариев.Картинка</segments>
  </rowPictureDataPath>
  <rowsPicture xsi:type="core:PictureRef">
    <picture>CommonPicture.ПиктограммыЭлементов</picture>
  </rowsPicture>
  …
</items>
```

Колонка `ГКСИ_ДеревоСценариевКартинка` типа `PictureField` (с `valuesPicture = CommonPicture.ПиктограммыЭлементов`) сохранена для отображения числового индекса рядом с иконкой.

## Логика индексов

`Module.bsl`, функция `ГКСИ_ИндексКартинкиГруппы` (группы):

| Тип группы                                  | Без пометки | С пометкой |
|---------------------------------------------|-------------|------------|
| Обычная группа                              | 0           | 1          |
| Группа-ветвление (`ТипГруппы = Ветвление`)  | 19          | 20         |

`Module.bsl`, процедура `ГКСИ_СоздатьУзелСценария` (элементы):

| Тип строки | Без пометки | С пометкой |
|------------|-------------|------------|
| Элемент    | 3           | 4          |

Тип группы берётся из реквизита справочника `ТипГруппы` (перечисление `ТипыГруппДемонстрационныхСценариев: Обычная / Ветвление`). Реквизит заимствован в расширение; если в конфигурации его нет, функция возвращает 0/1 для всех групп.

## Коллекция `ПиктограммыЭлементов`

В EDT двойной клик по `ПиктограммыЭлементов` → редактор коллекции. В нём есть кнопка «Добавить позицию» — для каждой позиции нужно загрузить свой png-файл.

Обязательные позиции для текущей логики:

| Индекс | Что должно быть |
|--------|-----------------|
| 0      | Обычная группа без пометки |
| 1      | Обычная группа с пометкой |
| 3      | Элемент без пометки |
| 4      | Элемент с пометкой |
| 19     | Группа-ветвление без пометки |
| 20     | Группа-ветвление с пометкой |

Для каждой позиции рекомендуется набор вариантов плотности (85/100/125/150/175/200/300/400%), как и для одиночной картинки.

## Как это работает

1. При построении дерева (`ГКСИ_ПостроитьДерево`) каждая строка получает числовое значение поля `Картинка` через `ГКСИ_СоздатьУзелГруппы` / `ГКСИ_СоздатьУзелСценария`.
2. Платформа видит `rowPictureDataPath` → берёт значение поля `Картинка` как индекс в коллекции `rowsPicture`.
3. На форме рисуется картинка с этим индексом.

## Как расширять

При добавлении нового типа строки:
1. Добавить новую позицию в коллекцию `ПиктограммыЭлементов` с нужной иконкой.
2. В `ГКСИ_ИндексКартинкиГруппы` или `ГКСИ_СоздатьУзелСценария` добавить ветку, возвращающую новый индекс.
3. Убедиться, что индекс не пересекается с уже занятыми.

## История

Изначально документ описывал «типовую» `ФормаСписка` с динамическим списком и `rowsPicture` через `ИндексКартинки` в схеме СКД. Затем форма была переписана на ручное дерево значений (`ФормаСпискаДеревоГрупп`), а логика индексов перенесена в `Module.bsl` (`ГКСИ_ИндексКартинкиГруппы` / `ГКСИ_СоздатьУзелСценария`). Механизм отрисовки остался стандартным — `rowsPicture` таблицы + числовое поле `Картинка`.
