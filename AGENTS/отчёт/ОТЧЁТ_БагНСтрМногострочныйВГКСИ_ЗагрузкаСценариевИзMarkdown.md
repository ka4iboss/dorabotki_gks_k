# Отчёт: баг `НСтр` с многострочным текстом в `ГКСИ_ЗагрузкаСценариевИзMarkdown`

Дата: 2026-09-09

## Симптом

При попытке выполнить загрузку сценариев через обработку
`ГКСИ_ЗагрузкаСценариевИзMarkdown` на финальном шаге
появляется окно подтверждения с пустым или обрезанным текстом.
Пользователь не понимает, что от него хотят, и загрузка не выполняется.

Заодно тот же класс ошибки в форме разрешения конфликтов: выпадающий
список «Решение» отображается без значений.

## Локализация

- `src/DataProcessors/ГКСИ_ЗагрузкаСценариевИзMarkdown/Forms/Форма/Module.bsl`,
  процедура `ВыполнитьЗагрузку` (формирование `ТекстВопроса`).
- `src/DataProcessors/ГКСИ_ЗагрузкаСценариевИзMarkdown/Forms/ФормаРазрешенияКонфликтов/Module.bsl`,
  процедура `НастроитьКолонкуРешения` (формирование списка выбора колонки
  «Решение»).

## Корень причины

Внутри аргумента `НСтр(...)` строковое значение располагается между
одинарными кавычками, идущими после `=`. Символ `|` **не работает** как
перевод строки внутри такого литерала — он интерпретируется как обычный
символ. Перевод строки срабатывает только в **обычных** строковых
литералах `"...|...|..."`.

В результате:
- В основной форме текст вопроса обрезался на первом `|` либо возвращал
  мусор, и пользователь видел пустое окно подтверждения.
- В форме конфликтов вызовы `НСтр("Пропустить'")` (без кода языка,
  без `=`) синтаксически некорректны — платформа возвращала пустую строку,
  и список выбора оставался пустым.

## Фикс

1. **Основная форма** — заменили многострочную запись с `|` на
   три отдельных `НСтр`, склеенных через `Символы.ПС`:

   ```1c
   ТекстВопроса = НСтр("ru = 'Выполнить загрузку сценариев в справочник?'")
       + Символы.ПС
       + НСтр("ru = 'Для существующих элементов будут применены выбранные решения.'")
       + Символы.ПС
       + НСтр("ru = '(Если проверка конфликтов не выполнялась - все совпадения будут пропущены.)'");
   ```

2. **Форма разрешения конфликтов** — заменили некорректные вызовы
   `НСтр("Пропустить'")` на корректный формат:

   ```1c
   ЭлементРешение.СписокВыбора.Добавить("Пропустить",  НСтр("ru = 'Пропустить'"));
   ЭлементРешение.СписокВыбора.Добавить("Обновить",    НСтр("ru = 'Обновить'"));
   ЭлементРешение.СписокВыбора.Добавить("Дублировать", НСтр("ru = 'Дублировать'"));
   ```

## Что проверено

- `GetMarkers` (тип `1c`) по обоим файлам: на изменённых строках остался
  только SU83 «неизвестный код языка ru» — известное ложное срабатывание
  EDT (линтер не имеет доступа к базе локализации расширения).
  Главная ошибка `SU83 формат не корректен` на затронутых строках ушла.
- `mcp__syntax-checker__validate` для обоих блоков правки — синтаксических
  ошибок нет.
