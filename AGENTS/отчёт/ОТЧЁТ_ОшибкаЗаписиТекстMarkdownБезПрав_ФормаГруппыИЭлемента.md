# ОТЧЁТ_ОшибкаЗаписиТекстMarkdownБезПрав_ФормаГруппыИЭлемента

Версия расширения: 2.35.0 → 2.35.1.

## Симптом

При недостатке прав (пользователь с ролью только на чтение) на форме
`ФормаГруппы` / `ФормаЭлемента` справочника `ДемонстрационныеСценарии`
нажатие на поле «Описание сценария» приводило к ошибке:

```
Поле объекта недоступно для записи (ГКСИ_ТекстMarkdown)
{...ФормаГруппы.Форма(795)}:Форма.Объект.ГКСИ_ТекстMarkdown = РМ_ЗаменитьСегментMarkdown(ПолныйТекст, ...
{...ФормаГруппы.Форма(213)}:РМ_СохранитьСегментMarkdownТекущегоЯзыка(ЭтотОбъект);
```

## Причина

Форма открыта без прав на изменение — главный реквизит `Объект` доступен
только для чтения. Обработчики нажатия (`ТекстСценарияПриНажатии` /
`ТекстСценарияЧтениеПриНажатии`, а также смена языка) вызывают
`РМ_СохранитьСегментMarkdownТекущегоЯзыка`, которая пишет текущий сегмент
Markdown обратно в `Форма.Объект.ГКСИ_ТекстMarkdown`. Чтение в этой процедуре
уже было защищено `Попытка`, а запись — нет, поэтому она и падала.

## Что сделано

Файлы:
- `src/Catalogs/ДемонстрационныеСценарии/Forms/ФормаГруппы/Module.bsl`
- `src/Catalogs/ДемонстрационныеСценарии/Forms/ФормаЭлемента/Module.bsl`

Процедура `РМ_СохранитьСегментMarkdownТекущегоЯзыка` (одинаковая в обеих формах)
изменена: запись сегмента обёрнута в `Попытка`/`Исключение`. Если объект
доступен только для чтения — сохранение пропускается, ошибка не возникает.

```1c
	Попытка
		Форма.Объект.ГКСИ_ТекстMarkdown = РМ_ЗаменитьСегментMarkdown(ПолныйТекст,
			Форма.ЯзыкСценария, Форма.ТекстMarkdownСтрока);
		Форма.Объект.ГКСИ_MarkdownСформирован = Истина;
	Исключение
		// Объект открыт без прав на изменение и доступен только для чтения,
		// поэтому сохранять сегмент Markdown некуда.
		Возврат;
	КонецПопытки;
```

При наличии прав на изменение поведение не меняется (запись выполняется как
раньше).
