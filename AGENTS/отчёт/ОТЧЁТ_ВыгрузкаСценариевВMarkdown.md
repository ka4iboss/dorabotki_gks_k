# Отчёт: обработка `ГКСИ_ВыгрузкаСценариевВMarkdown`

**Версия расширения:** 2.33.2 → 2.34.0
**Дата:** 2026-09-24

## Задача

Реализовать обработку, обратную `ГКСИ_ЗагрузкаСценариевИзMarkdown`: выгружать
инструкции (сценарии) из базы в файлы Markdown.

## Принятые решения (согласованы с пользователем)

- **Источник текста** — реквизит `ДемонстрационныеСценарии.ГКСИ_ТекстMarkdown`
  (конвертация HTML→MD не используется).
- **Гранулярность** — одна инструкция (корневая обёртка) = один `.md`-файл.
- **Область** — выбранная инструкция + опционально «все».
- **Картинки** — файлы рядом с `.md`, ссылки `![[имя файла]]`.
- **Языки** — выгружается выбранный язык (по умолчанию `ru`).
- **Запись файлов** — каталог на машине клиента через диалог выбора.
- **Режим** — фоновое задание с прогрессом.
- **Кодировка** — UTF-8 без BOM, переводы строк LF.
- **Существующие файлы** — перезаписываются без вопросов.

### Серверная логика (`ГКСИ_ВыгрузкаСценариевВMarkdown`)

- `ПолучитьКорневыеОберткиИнструкций()` — корневые обёртки (самоссылки РС).
- `ПолучитьКорневуюОберткуИнструкции(Ссылка)` — корень для произвольного узла.
- `ПодготовитьФайлыКВыгрузке(МассивКорней, КодЯзыка, АдресПрогресса)` — 3 этапа:
  сбор узлов (по корню, один запрос текстов), картинки, формирование файлов.
- Вспомогательные: `СвязиГруппПоКорням`, `СобратьУзлыРекурсивно`,
  `СортироватьПоКоду`, `ТекстыИНаименованияПоСсылкам`, `СобратьТекстИнструкции`,
  `РешеткиПоУровню`, `СобратьКодыКартинокИзТекста`, `ЭтоКодФайла`,
  `ПодготовитьКартинки`, `РазвернутьСсылкиНаКартинки`, `УникальноеИмяФайла`,
  `ОчиститьИмяФайла`.

Особенности реализации:

- Связи группируются **по измерению `КореньИнструкции`** — иначе у общего узла
  выбирался бы случайный родитель.
- Тексты всех узлов читаются **одним запросом** (нет обращений к базе в цикле).
- Устранён маркер EDT `SU95` (запрос в цикле).

### Модуль длительных операций

`ПодготовитьФайлыФоново(ПараметрыЗадания, АдресРезультата)` — вызывает
`ПодготовитьФайлыКВыгрузке`, кладёт результат в ВХ по
`АдресРезультатаВыгрузки`, пишет прогресс (этапы 1–4).

### Форма

- Реквизиты: `ГКСИ_ИнструкцияИсточник`, `КодЯзыка`, `КаталогВыгрузки`,
  `ПроцентГотовности`, `ТекстПрогресса`, `АдресПрогресса`, `АдресРезультата`,
  `ИдентификаторЗадания`.
- Команды: `Выгрузить`, `ВыгрузитьВсе`, `ВыбратьКаталог`.
- Запуск фонового задания + опрос прогресса (как в загрузке).
- Сохранение файлов на диск — `НачатьПолучениеФайловССервера` (без диалога,
  базовый каталог = `КаталогВыгрузки`), файлы предварительно помещаются в ВХ
  с УИД формы.

## Проверка

- `mcp__syntax-checker__validate` + `GetMarkers` по всем новым файлам.
- Ошибок (`severity: error`) нет. Остаются только предупреждения, принятые в
  проекте как ложные: `SU83` (`НСтр` с кодом `ru`) и `SU29` (тип коллекции в
  документирующем комментарии).

## Ограничения

- HTML→Markdown на сервере не конвертируется — источник только `ГКСИ_ТекстMarkdown`.
- Хранимый текст нормализован (одиночный `\n`, пустые строки потеряны), поэтому
  round-trip не даёт байтового совпадения с исходным `.md`.
