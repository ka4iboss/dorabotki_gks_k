# ОТЧЁТ_ПраваЧтенияИТолькоПросмотр

Версия расширения: 1.62 → 1.63.

## Что сделано

### 1. Роль `ГКСИ_ЧтениеИнструкций` — расширены права

Файл: `src/Roles/ГКСИ_ЧтениеИнструкций/Rights.rights`.

Добавлены права:

| Объект | Права | Зачем |
|---|---|---|
| `InformationRegister.ГКСИ_ГруппыСценариев` | `Read` | Программное чтение альтернативной иерархии сценариев — нужно построителю альбома `ГКСИ_АльбомПроцессов`. |
| `Catalog.ДемонстрационныеСценарии` | `Read` | Открытие формы списка/элемента/группы сценариев, чтение иерархии и описаний. |
| `Catalog.ДемонстрационныеСценарии.Form.ФормаЭлемента` | `View` | Просмотр формы элемента сценария. |
| `Catalog.ДемонстрационныеСценарии.Form.ФормаГруппы` | `View` | Просмотр формы группы сценариев. |
| `Catalog.ДемонстрационныеСценарии.Form.ФормаСпискаДеревоГрупп` | `View` | Просмотр формы списка (дерево групп). |
| `Catalog.ДемонстрационныеСценарии.Form.АльбомПроцессов` | `View`, `Use` | Открытие и использование формы «Альбом процессов» (формирование альбома по группе/выделенным). |
| `Catalog.ДемонстрационныеСценарииПрисоединенныеФайлы` | `Read` | Чтение присоединённых HTML-файлов сценариев (для отображения картинок через `ГКСИ_ДанныеИзображенийMarkdownПовтИсп`). |

Существующие `<object>` для атрибутов и стандартных реквизитов `Catalog.ГКСИ_ФайлыИнструкций` с `View=false, Edit=false` оставлены без изменений: реквизиты скрыты в форме, но `Read=true` обеспечивается настройкой `setForAttributesByDefault=true` на уровне справочника, поэтому программное чтение (через запрос, через ссылку) не приводит к ошибке «Объект не найден». Это соответствует семантике «показать только имя файла, не давая редактировать».

### 2. Форма `ФормаЭлемента` для `Catalog.ГКСИ_ФайлыИнструкций`

Файл: `src/Catalogs/ГКСИ_ФайлыИнструкций/Forms/ФормаЭлемента/`.

Создана новая форма `ФормаЭлемента` (`OBJECT`) и установлена как `defaultObjectForm`. Форма генерируется layout-генератором EDT: содержит 5 элементов (`Код`, `Наименование`, `Расширение`, `Описание`, `ХешSHA256`) и автогенерируемую командную панель.

Модуль формы (`Module.bsl`) переводит форму в режим «только просмотр» при создании:

```1c
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    ТолькоПросмотр = Истина;
    Элементы.Объект.ТолькоПросмотр = Истина;
    // Скрываем кнопки "Редактировать", "Записать", "Записать и закрыть"
    // из автогенерируемой командной панели, чтобы пользователь не мог
    // переключить форму в режим редактирования.
    КнопкаРедактировать = Элементы.Найти("ФормаРедактировать");
    Если КнопкаРедактировать <> Неопределено Тогда
        КнопкаРедактировать.Доступность = Ложь;
        КнопкаРедактировать.Видимость = Ложь;
    КонецЕсли;
    КнопкаЗаписать = Элементы.Найти("ФормаЗаписать");
    Если КнопкаЗаписать <> Неопределено Тогда
        КнопкаЗаписать.Доступность = Ложь;
    КонецЕсли;
    КнопкаЗаписатьИЗакрыть = Элементы.Найти("ФормаЗаписатьИЗакрыть");
    Если КнопкаЗаписатьИЗакрыть <> Неопределено Тогда
        КнопкаЗаписатьИЗакрыть.Доступность = Ложь;
    КонецЕсли;
КонецПроцедуры
```

Создание формы в EDT и установка её как `defaultObjectForm` выполнены через `1C_EditMetadata createObjectForm`. Удалена созданная по ошибке `ФормаГруппы` (`removeObjectForm`) — справочник не иерархический, форма группы не нужна.

### 3. Заимствован `Catalog.Глоссарий` в расширение

Файл: `src/Catalogs/Глоссарий/Глоссарий.mdo` (создан через `1C_EditMetadata adoptObject`).

Справочник `Глоссарий` основной конфигурации (типовой объект БСП) заимствован в расширение и добавлен в подсистему `ГКСИ_ИнструкцииОписанияДемонстраций` через `addObjectReference property_name=content`.

Логика глоссария (чтение терминов, обогащение HTML, панель терминов в формах сценариев) уже была реализована в `CommonModule.ГКСИ_Глоссарий` (см. `Описание.md` §14, `ОТЧЁТ_Глоссарий.md`) — она работала с типовым объектом из основной конфигурации. Заимствование нужно, чтобы:

1. Справочник `Глоссарий` отображался в интерфейсе подсистемы `ГКСИ_ИнструкцииОписанияДемонстраций` (раздел командного интерфейса).
2. Был доступен для раздачи прав в ролях расширения без необходимости модифицировать типовые роли.
