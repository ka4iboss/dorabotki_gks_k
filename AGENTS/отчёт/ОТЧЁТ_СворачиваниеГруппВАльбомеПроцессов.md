# ОТЧЁТ — Сворачивание групп в «Альбоме процессов»

## Задача

На форме `ДемонстрационныеСценарии.АльбомПроцессов` дать возможность сворачивать
и разворачивать группы альбома: клик по заголовку группы скрывает/показывает её
содержимое, плюс кнопки «Развернуть всё» и «Свернуть всё» в командной панели формы.

## Решения пользователя

1. Состояние при открытии: **все группы раскрыты** (изменено по итогам
   приёмки — изначально планировались раскрытые корневые и свёрнутые вложенные).
2. Сворачиваются группы **всех уровней** (включая вложенные).
3. Добавить **обе кнопки** — «Развернуть всё» и «Свернуть всё».
4. **ОС не проверять**: тег `<details>` выводится всегда (на Linux-клиенте вид может
   быть некорректным — принято сознательно).

## Что сделано

### 1. Разметка групп — нативный `<details>`

Файл: `src/CommonModules/ГКСИ_АльбомПроцессов/Module.bsl`,
процедура `ГКСИ_ВывестиГруппуВМассивСтрок`.

Вместо одиночного заголовка группа выводится обёрткой:

```html
<details class="album-group-details" open>            <!-- open только для Уровень = 1 -->
  <summary class="album-group-summary">
    <hN class="album-group">Код Наименование</hN>
  </summary>
  ...описание группы, таблицы сценариев, подгруппы (рекурсивно)...
</details>
```

- Все группы (включая вложенные) — с атрибутом `open`; при открытии альбома
  развёрнуто всё содержимое.
- `</details>` добавляется в конце процедуры и перед ранним `Возврат`
  (ветка «нет прямых потомков»), чтобы блок всегда был закрыт.
- Механизм — нативный для WebKit (тот же приём, что в типовой ERP, форма
  `ПравилаИнтеграцииС1СДокументооборотом3.ВыражениеНаВстроенномЯзыке`).
  JS-состояния нет, сервер при сворачивании не вызывается.

### 2. CSS

Файл: `src/CommonModules/ГКСИ_АльбомПроцессов/Module.bsl`,
функция `ГКСИ_СобратьДокумент` (блок `<style>`):

```css
.album-group-details { margin-top: 14pt; }
.album-group-summary { cursor: pointer; }
.album-group-summary > .album-group { display: inline; margin-top: 0; }
.album-group-summary:hover > .album-group { text-decoration: underline; }
@media print { .album-group-details > *:not(summary) { display: block !important; } }
```

`display: inline` у заголовка внутри `<summary>` — выравнивание маркера:
блочный `<hN>` создаёт собственную строку, из-за чего треугольник-маркер вставал
строкой выше заголовка. Со строчным заголовком маркер и текст идут одной строкой.
Кликабелен весь `<summary>`; `:hover` с подчёркиванием — подсказка, что заголовок
нажимаемый.

Правило `@media print` — попытка показать содержимое свёрнутых групп при печати
(best-effort; требует проверки в WebKit, см. «Известные ограничения»).

### 3. Команды и кнопки формы

Файл: `src/Catalogs/ДемонстрационныеСценарии/Forms/АльбомПроцессов/Module.bsl`.

- В `ГКСИ_ПриСозданииНаСервере` добавлен вызов `ГКСИ_ДобавитьКомандыСворачивания()`.
- `ГКСИ_ДобавитьКомандыСворачивания()` — серверный хелпер, вызывает
  `ГКСИ_ДобавитьКомандуИКнопку` для двух команд.
- `ГКСИ_ДобавитьКомандуИКнопку(ИмяКоманды, Заголовок, Подсказка, ИмяДействия)` —
  по образцу `РаботаСФайлами`: `Команды.Добавить(...)` + `Элементы.Добавить(...,
  Тип("КнопкаФормы"), Элементы.ФормаКоманднаяПанель)`, `Кнопка.ИмяКоманды`,
  `Отображение = ОтображениеКнопки.Текст`. Защита от повторного добавления — по
  `Команды.Найти(...)`.
- Клиентские обработчики `ГКСИ_РазвернутьВсеГруппы` / `ГКСИ_СвернутьВсеГруппы`
  делегируют в `ГКСИ_УстановитьОткрытиеВсехГрупп(Открыть)`.
- `ГКСИ_УстановитьОткрытиеВсехГрупп(Открыть)` в `Попытка/Исключение` перебирает
  `Документ.getElementsByTagName("details")` и ставит/снимает атрибут `open`
  (`setAttribute` / `removeAttribute`). Сервер не вызывается, альбом не перестраивается.

## Известные ограничения

- **Печать свёрнутого альбома.** По умолчанию раскрыто всё, поэтому этот риск
  актуален только для групп, свёрнутых вручную. Правило `@media print` пытается
  принудительно показать их содержимое, но гарантия зависит от реализации
  `<details>` в WebKit. Если при печати содержимое теряется — печатать после
  кнопки «Развернуть всё».
- **Linux-клиент.** По решению пользователя ОС не проверяется; на Linux-клиенте
  (не WebKit) `<details>` может отображаться некорректно.
- **`getElementsByTagName`/`setAttribute`** на внешнем DOM-объекте 1С ранее в проекте
  не применялись (использовались `getElementById`, `Документ.images[i]`). Если при
  проверке кнопки не сработают — fallback: встроить `<script>` в HTML альбома и
  вызывать функцию через `Элементы.ТекстHTML.Документ.defaultView.<функция>(...)`
  (приём уже применяется подсистемой Markdown: `markdownConvert()`, `clean_bbox()`).
